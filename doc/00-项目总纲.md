## 1. 项目定位

| 项目 | 当前事实 |
| --- | --- |
| 当前开发版本 | `V3.0.0`；评委本机体验Demo |
| 正式名称 | 岗链智训——面向职业教育高水平专业群建设的融媒体内容生产与治理岗位群教学实训智能体平台 |

## 2. 当前交付状态

V2.7完成旧前端清理，V2.8接通档案入口、个人单课、地图、MCP人物动作、关系记忆、私人采访本和课前创作，V2.9接入三地区深度内容、按课成果与评价，以及后续训练的单课衔接。V3.0完成角色流程回归、个人作品归档、教师逐维评阅、恢复与文档收尾。体验步骤与验证边界见[成品交付手册](01-子文档/19-V3成品交付与验收.md)。

基础目录保留5门、30章与106个知识ID；现场课程扩充为蟳埔、榕江赛事街区、青岚山地景区三地区，各20场景、20名主要人物。每课12个调查方向和4种轮换任务来件，成果模板与评价依据分别绑定本课。课程按55分钟工作量设计，尚无真人计时验证，不用自动化执行耗时冒充学习时长。详见[课程内容与评价](01-子文档/18-V3课程内容与作品评价.md)。

本轮面向评委可运行Demo；SQL内容库与原世界/作品Store保持职责，采用既有身份绑定和单写者恢复。真实师生意见、专业效度、生产SSO和完整多租户平台没有因此被宣称完成。设计与权威入口见[交互骨架](01-子文档/17-V3交互骨架与内容架构.md)。

## 3. 产品体验

| 用户 | 建议体验顺序 |
| --- | --- |
| 教师 | 课程导演 → 课前人物或委托配置并发布 → 学生档案 → 当前课程、已交作品及评价 → 复核与后续练习 |
| 学生 | 课程档案 → 选择课程或教师委托 → 地图探索、人物交流、私人笔记 → 作品送审与可选附件 → 完成本课及查看反馈 |
| 管理员 | 角色入口 → 实际世界日志与评价依据 → 独立模型尝试 → 业务收据和恢复状态 |

默认启动Web为http://127.0.0.1:4173，API为http://127.0.0.1:3001，数据为.local/data。根目录启动脚本及复用/空白演示说明见[01第11节](01-开发者文档.md#11-启动和体验当前版本)。

## 4. 总体架构

教师任务与资料依托ContentStore；学生行动进入WorldSimulationEngine；作品、课程、评价和日志共享同一来源解释；正式评价和后续训练保留人类确认。14种岗位智能体职责与实际每轮被选择的运行分开，程序事件不冒充模型协作。

具体结构、存储与接口只在[开发者文档](01-开发者文档.md)维护；结构理由见[04](04-智能体设计架构.md)。

## 6. 工作区与权威边界

唯一正式前端位于apps/web；旧独立前端、四套旧演示数据已可恢复迁入.local/retired-v260，有用视觉资料已整合。活动依赖、当前数据、本机密钥和用户未提交的参赛/视频资产保留。具体处置见[01第10节](01-开发者文档.md#10-程序目录与关键入口)。

## 7. 外部条件与诚实边界

| 条件 | 当前口径 |
| --- | --- |
| 工程验收 | 以本版实际检查为准，历史截图或固定样例不能替代 |
| 专业准确性 | 来源可定位，有限规则与教师复核已接通；外部专家效度尚未建立 |
| 真实用户反馈 | 已准备目标师生试用提纲与记录入口；工程仿真师生不是2—3名真实职教师生反馈 |
| 多智能体与教学效果 | 非零实证尚不足，不宣称普遍优于基线或效果已成立 |
| 平台 | 依用户已确认答疑，不限开发平台；星辰保留可选适配，线上调用以收据为准 |
| 报名与校内选拔 | 用户确认已完成；本轮未代核验报名系统 |
| 提交材料与签字 | 按原题和学校要求核对；真实签字、盖章、身份与评价由本人提供 |
