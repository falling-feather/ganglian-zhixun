## 1. 样板课要解决什么

拟用课题名：**“簪花之外：蟳埔社区的一次融媒体采编委托”**。学生作为融媒体中心实习记者，面向拟来访游客及关注社区生活的读者，自主发现一个值得报道的问题，完成有来源、有现场经历、有编辑判断的报道初稿，并处理一次与自己选择有关的反馈。

一节样板课的共同目标是选题、采访、核验、生产、发布判断与修订。学生可以选择不同的报道角度、信源组合、行动顺序与表现形式。优秀作品可以来自公共服务调查、人物故事或文化解释，不要求人人拜访全部人物，也不要求先做一次错误决策才能学会纠错。

成果简化为“一份主要报道＋可追溯证据包＋简短复盘”仍是后续提议。本轮沿用现有七项必交、九类成果、作品修订与正式评分合同；新调查策略只描述所需材料、信源与经历，不把“证据已备齐”显示为通关或成绩。

“十个学生玩出十种路径”作为课程容量目标：至少设计并跑通十种在选题、信源、关键取舍或修订上有实质区别的合理策略。不能承诺真实十名学生必然各选一条不同路线，也不把随机分配皮肤、不同台词或行走顺序计为十种学习结果。

## 2. 调研如何改变课程

教育部专业教学标准把融媒体采编、运营与信息审核列为职业面向，专业课程可依区域实际开展项目式、情境式教学；制作发布实战涵盖采集、加工和分发。因此本课应让采访发现进入后续作品与发布判断，不能停留在人物聊天。依据为[专业教学标准PDF第1、3、7页](https://www.moe.gov.cn/s78/A07/zcs_ztzl/2017_zt06/17zt06_bznr/bznr_zyjyzyjxbz/gdzyjy_zk/zk_xwcbdl/xwcbdl_gbysl/202502/P020250207548141306012.pdf)。

蟳埔的课程内容可围绕四种视角展开，以下是从资料形成的**课程设计推论**，不是对真实居民的调查结论：

| 视角 | 资料起点 | 转换为学生的问题 |
| --- | --- | --- |
| 生活与技艺 | 地方标准分别说明习俗、工艺与保护传播，包含日常与节庆的不同语境 | 一幅好看的画面之外，还缺少哪些劳动、生活与技艺信息？ |
| 保护与经营 | 村落保护发展总结同时涉及生活空间、经营利用和公共设施 | 不同主体对同一处空间有什么不同需要？哪些解释还需要当事人补充？ |
| 传播与口径 | 文旅传播报道带有明确报道时点和统计范围 | 旧新闻中的客流与传播量可以怎样引用？哪些概念不能互换？ |
| 游客与居民服务 | 交通部门答复包含旅游接驳、居民出行、需求和成本的取舍 | 一条“方便游客”的建议是否也考虑居民使用？记者还应问谁？ |

对应来源：[地方标准发布页](https://scjgj.quanzhou.gov.cn/xxgk/zfxxgk/fdzdgknr/ywgz/202407/t20240722_3062306.htm)、[村落保护发展总结](https://zfjsj.quanzhou.gov.cn/xygl/wjtz_48385/202511/t20251111_3229389.htm)、[文旅案例报道](https://wlt.fujian.gov.cn/wldt/btdt/202412/t20241209_6589570.htm)、[交通部门答复](https://jtj.quanzhou.gov.cn/zfxxgkzl/xxgkml/rddbjy/rdjy/202506/t20250603_3176070.htm)。材料日期与取得边界统一登记在[调研来源](../../资料/04-职业教育依据/05-蟳埔样板课调研来源.md)。具体工艺解释仍需专业复核，不能由模型随意补全。

教学组织借鉴真实任务中的学生决策权，人物机制参考记忆、计划与即时反应，分支采用“能够汇合但保留先前选择影响”的组织方式。依据分别为[真实任务研究摘要](https://ro.ecu.edu.au/ecuworks/2259/)、[Generative Agents论文](https://arxiv.org/html/2304.03442v2)、[Ink官方分支文档](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md)。这些材料提供设计方法，不替代本项目的教学效果验证，也不要求换开发框架。

## 3. 空间、入口与时间

### 3.1 首屏提供四种立即可做的事

| 可见入口 | 学生能立即做什么 | 可能带来的下一步 |
| --- | --- | --- |
| 公示栏 | 走近、放大、查看公告日期和出处，记录一个疑问 | 向公共联络员核对；寻找游客或居民的使用体验 |
| 林师傅 | 打招呼、问路、说明采访想法、请求引荐，也可以告别 | 公共观察提示；征求特定场所进入或介绍受访者的机会 |
| 沿街公共区域 | 观察公开环境；接触愿意交谈的游客、商户或路人 | 游客服务、商业经营、社区生活等选题线索 |
| 手机中的编辑委托 | 阅读任务、向编辑澄清受众、给研究者留言预约 | 先约后访，或先做公开资料核验等待回复 |

林师傅的权力限定为他实际协调的入口和引荐。拟取消“所有商户、工坊和游客都必须经同一门卫”的统一前提；私人小院、内部教学活动和特定采访仍遵守各自约定。公开可到达、可以交谈、同意录制、同意某用途公开，是不同事实。

至少两条完整报道策略能够不经林师傅引荐完成。拒绝和他交流不自动扣分；擅入已明确受限空间则产生对应后果。公示栏和资料点不能藏在同一把锁后，否则首屏看似有多个入口，实际仍只有一条通路。

### 3.2 复用七个既有地点

| 既有节点 | 深化后的作用 | 需要补齐的交互 |
| --- | --- | --- |
| 巷口 | 问路、建立来意、观察公共环境 | 独立公示栏热点、公共支路、主动告别；不只保留院门 |
| 居民小院 | 有具体邀请和时间边界的居民采访 | 对话、观察劳动对象、限定记录、临时离开与续访 |
| 资料联络点 | 公共服务与原始资料核对 | 公告版本、咨询窗口、信息时点、研究者联系渠道 |
| 簪花工坊 | 观察技艺和传习活动 | 选择看完整步骤或短访，工具细节与过程素材 |
| 沿街店铺 | 经营者视角和商业合作取舍 | 价目/服务说明、样片出处、独立采访与素材使用分开 |
| 移动编辑台 | 现场随时整理与转向 | 保留疑问、草拟选题、调整采访计划，不强迫立即填齐全表 |
| 编辑部 | 作品整合、编辑沟通与发布后回应 | 以本人的材料和选择触发审稿意见及修订任务 |

先使用现有图片的局部探索、人物位置和物件热点。是否为公示栏另设一个近景子节点，由视觉密度决定，不以新增地图数量作为深度指标。继续沿用普通透视图和节点漫游，不引入骨骼动画前提。

### 3.3 一套能理解的时间

当前55分钟仅作为待调试的虚拟任务窗口。建议对赶路、采访、查证和等待规定可解释的时间成本；阅读、输入和打开工具不按现实打字速度扣分。进入耗时行为前让学生知道预计成本，长行动允许结束，教师可以暂停。

人物在场、预约、承诺到期与截止时间应消费同一权威时钟。邮件逾期不代表资料已到，人物答应回访不代表马上回到场景。学生可以等待，也可以并行调查、缩小选题或换信源。课时时长及行动成本要在样板课试走后校准，不提前把未验证数值写成教学标准。

## 4. 十个人物的具体设计

以下沿用已有角色名称与实体ID，补充的生活目标、私人压力、言行和时间条件均为**合成教学人物设定**。每个人至少有一件与学生无关的事要完成；可以不知道、记不清、改变安排，也可以反问学生，但不能任意编造公开事实。

| 人物 | 自身目标与矛盾 | 知识边界与独有价值 | 自然行为、拒绝与恢复 |
| --- | --- | --- | --- |
| 林师傅：现场协调者 | 想让正常采访顺利，也要维持出入口秩序；不希望每个人都把他当“开门的人” | 知道公共路线、当日活动和可询问对象；不能代居民同意采访，也不是非遗史专家 | 问候会回应，问路会指路。忙时先处理现场事务；可解释限制、给公共替代入口。学生改变范围后重新协商，不要求背诵口令 |
| 阿环：社区受访者 | 希望生活中的劳动与经验被看见，又不想耽误手头安排 | 能讲自己的日常和具体经历；个人感受不能升级为“所有居民都这样想” | 愿意边做事边短聊；问题过大时请学生说具体。临时离开后可留言续访；拒绝近景时仍可能同意匿名文字或环境观察 |
| 黄老师：技艺教学者 | 想把过程讲准确、把学员带好；不愿只为记者重复摆拍 | 熟悉课程设定中的工序和教学经验；历史起源与名录层级须查来源 | 可让学生旁观一段教学再提问；时间不足时只能在“看完整步骤”和“短访”间选择。错过后可查记录并预约补问 |
| 陈老师：研究者 | 想让材料被准确解释；同时有其他工作，无法随时长谈 | 能辨别证据层级和提出研究问题；不能证明未调查事实或为任意结论背书 | 可以接受普通问候和留言，准备具体问题会提高交流效率。可约时间、答应邮件；忙碌分支中可能延误，学生可催办或独立查证 |
| 吴姐：商户 | 希望服务与手艺获得展示，也希望经营回报；同时在意被一概说成“只追流量” | 熟悉自己的服务、顾客需求和可提供的样片；不拥有所有素材或所有人的许可 | 可接受纯采访、有限素材合作或拒绝合作；不把她写成必然诱导作弊的反派。谈不拢仍可记录她公开表达的商业立场 |
| 蔡主任：公共信息联络员 | 希望发布信息准确且能服务公众；手中资料可能更新滞后 | 能说明公告发布方、统计时点和咨询渠道；不能替其他部门或社区所有人作证 | 允许学生指出版本差异，确认不了时明确需要回查。补回执可能晚于采访窗口，学生应决定限定发布还是等待 |
| 许老师：素材权利联络人 | 希望创作者署名、使用范围与合作约定得到落实 | 能核对特定素材的提供者和许可链；不是替所有作品裁判的全知法律机器人 | 会围绕具体文件追问用途、平台和修改方式；许可不足时给出补充路径，也接受学生决定不用该素材 |
| 周女士：游客 | 想获得实用体验信息、留下旅行记录，也希望自己的话没有被断章取义 | 能讲亲历体验；不掌握实时客流全貌或社区文化的权威解释 | 可以主动问记者做什么；接受短访不等于接受所有画面用途。赶时间时留下短意见，或婉拒，学生可换观察方式 |
| 乔安：平台值守 | 需要按时安排内容，又要控制未经核实的表达和错误扩散 | 掌握本次教学平台的发布规则与反馈；不能预知真实传播量 | 区分“表达需补充”和“事实需更正”；允许说明理由后维持有证据的判断。到期窗口与修订通知持续存在 |
| 陈编辑：责任编辑 | 要一篇有价值且能按时交付的报道，也要让学生自己完成判断 | 知道任务受众和编辑要求；只能基于已获材料建议，不能替学生凭空采访 | 开场可讨论选题，碰壁时帮助缩小问题；不强制所有人走同一路线，不每回合输出长篇法规，不代写成稿 |

常用角色之外，可在公共路径加入两类轻量路人：正在搬运的工作人员、匆忙路过的游客。使用程序回应即可，例如“抱歉，我这会儿腾不开手。你可以去前面的咨询点问问。”重复点击不刷关系、不刷分，也不为这些角色额外常驻大模型任务。

每份人物配置建议包含：公开自我介绍、当前工作、想获得什么、担心什么、知道什么与不知道什么、可讨论的话题、在场安排、对学生承诺的记忆、可提供材料和改变立场的条件。表达变化依据具体行为，不用一条“好感度”解释所有反应；事实分歧也不等于人物讨厌学生。

## 5. 自然交谈与真实后果

### 5.1 开场应当像人与人见面

拟议对话示例：

| 回合 | 对话 | 系统应发生什么 |
| --- | --- | --- |
| 学生 | 林师傅你好。 | 已知学生点的是林师傅，直接进入这个人的会话；不要求同时提供任务、材料和结果 |
| 林师傅 | 你好，是来逛逛，还是想找人聊聊？ | 以角色口吻澄清来意，不产生放行事实 |
| 学生 | 我是学校融媒体实习记者，选题还没想好，想看看这儿平常都忙些什么。 | 接受“不确定选题”这一真实状态；保留学生原话 |
| 林师傅 | 可以先看外面的公示栏和沿街店铺。里面有住户正在忙；要找居民聊，我可以先替你问一声。 | 显示两个公共去处和一个可请求的引荐，均不自动替学生选择 |
| 学生 | 我先看公示栏，等有具体问题再回来。 | 结束当前交谈，记住后续意向；不等同于已经请求引荐或获得采访许可 |

若学生只说“我想进去看看”，人物可以追问“你想去哪儿、看什么？”；已足够明确的正常采访不再强迫填写一段标准声明。越界行动仍受业务规则约束，但说明应来自场景与人物，例如“里面现在不方便，我可以帮你问一个时间”。

### 5.2 交谈、行动与推断分层

| 层 | 接受的内容 | 可产生的结果 |
| --- | --- | --- |
| 日常交谈 | 问候、问路、致谢、犹豫、澄清、拒绝、改口 | 人物回复、会话记忆、可选择的下一步；不授予权限、不形成成绩 |
| 职业沟通 | 问题、追问、证据出示、安排协商 | 有来源的回答、待确认承诺、行动提议；缺信息时自然补问 |
| 权威行动 | 进入、录制、确定预约、接受使用条件、提交或发布 | 交世界服务核对条件并结算，返回明确事实或原因 |
| 过程评价 | 已发生行为、实际引用、作品变化和学生理由 | 带情境的能力证据；不以礼貌词命中次数判断能力 |

模型可提出“愿意介绍阿环”，但只有结算确认才算完成引荐。语句中的未来意向、假设、转述和已执行动作要分开；学生说“过会儿我可能联系她”，不能使人物立即出现。

人物会话使用该人物自己的经历与观察。内部复用同一个推理模板，不应把阿环的名义投射到林师傅身上。来源不足时人物可承认不清楚、提出查询渠道；不让所有NPC都从全库回答所有问题。

## 6. 可组合的现场事件

每个事件编写可观察前兆、触发条件、人物目标、有效时段、合法行动、机会成本、实际后果和恢复路径。避免“时间一到强迫所有学生经历同一事故”，也避免没有任何提示的随机惩罚。

| 事件 | 学生看见的前兆 | 至少两种合理应对 | 保留的后果与评价证据 |
| --- | --- | --- | --- |
| E01：最初没有好选题 | 编辑委托较宽，现场出现两类不同线索 | 先观察再提问；先找编辑澄清受众；查公开材料形成问题 | 选题如何从线索变具体；不能因没有一次说出题目就拒绝交谈 |
| E02：居民临时离开 | 人物提到约定，随后收到消息 | 留言续访；采访别人；缩小报道范围 | 实际约定、未完成问题与替代信源；不抹掉已经取得的记录 |
| E03：研究者需预约 | 手机可见可咨询时段及准备建议 | 先发问题清单并平行调查；先查资料再预约；不用专家直接核实可证事实 | 时间管理、提问质量和独立查证；预约不是唯一通关钥匙 |
| E04：承诺的邮件没到 | 已确认预计时间，届时邮箱仍无附件 | 礼貌催办；查原文；告知编辑并调整表达 | 待办管理、证据缺口和内容克制；“答应发送”不能计为已获证据 |
| E05：公告口径发生变化 | 新旧版本的日期、范围不同 | 联系发布方；保留时点作限定解释；等待再发 | 版本比对、信息时效与保留不确定性的理由 |
| E06：采访或拍摄被拒绝 | 对方明确当前条件不合适 | 接受拒绝另访；协商匿名文字、不同时间或替代画面 | 尊重边界和继续完成报道的能力；未采访某人本身不扣分 |
| E07：商业素材带来条件 | 样片好看，但提供方希望获得特定呈现 | 核清范围并披露后有限使用；自行采集；仅采访经营者观点 | 素材质量、机会成本与编辑判断。复用现有商业灰度取舍 |
| E08：不同来源互相矛盾 | 转引中的名称、年份或数字与原件不同 | 回溯原件；请教具体差异；删去无法确认的断言 | 哪个命题得到什么证据，哪些仍未证实；不能“取平均”消除矛盾 |
| E09：画面表达造成误解 | 当事人看到片段后说明省略的语境 | 补充说明或重剪；在证据充分时解释并维持判断 | 修改与维持都可合理，依据是记录和理由；复用发布后灰度取舍 |
| E10：窗口临近仍缺材料 | 编辑给出剩余时间，关键问题仍有空缺 | 缩小题目交付；发布限定快讯后更新；申请延后深入稿 | 完成度与时效取舍；不强迫学生编数字、编引语补齐表格 |

E02—E04在独立前端样板中已有有限演示，正式课程要重新接入权威事件与消息，不能把浏览器本地状态直接写成服务端事实。其余事件优先复用现有节拍、物件、冲突域与案例，不再另起一套并行脚本。

预约的申请、确认、到期、完成、取消与错过需要区分；邮件的承诺、待发送、逾期、送达、阅读与回复也要区分。具体状态字段在实施时统一定义。消息是教学仿真渠道，不自动向外部真实邮箱或微信发送。

## 7. 十二种可完成的探索策略

下表是拟议的课程容量与验收样例，不是十二条必须依次完成的任务。所有路线共享同一个委托和世界；可中途转向、汇合，但材料、时间、关系、承诺与修改记录继续有效。

| 策略 | 典型路径与选题 | 关键取舍和材料 | 与其他路径的实质差别 |
| --- | --- | --- | --- |
| R01 社区日常 | 林师傅引荐→阿环短访→观察劳动→查背景 | 保留个人经验范围，选择生活细节而非只拍造型 | 居民叙事与生活场景为主 |
| R02 技艺过程 | 公共工坊咨询→观察一段教学→黄老师补问→原文比照 | 完整工序与短时问答之间分配时间 | 过程解释、镜头次序与技艺信息为主 |
| R03 文化解释 | 公示栏→原始标准与转引对照→研究者问答 | 明确能证实的范围，不把专家口头判断代替文献 | 来源层级与概念解释为主；不需门卫引荐 |
| R04 游客服务 | 公共街区观察→周女士短访→蔡主任核对 | 区分一次体验与整体情况，标记信息时点 | 具体服务问题与实用表达为主；不需进入小院 |
| R05 居民与游客共同使用 | 公开交通资料→公共路线观察→分别询问两方 | 记录不同需求，主动寻找与初始想法不一致的材料 | 利益权衡与多方验证为主；不靠单一受访者结论 |
| R06 经营者视角 | 沿街店铺自主咨询→吴姐→对照访客体验 | 可以不用商户视频，只呈现有边界的经营观点 | 商业叙事与独立采访为主；不需门卫引荐 |
| R07 透明素材合作 | 吴姐样片→许老师核权→编辑协商→有限使用 | 接受有限合作并说明关系，承担后续台账与版本成本 | 与R06的“完全不用样片”同样可能合理 |
| R08 替代画面报道 | 受访者拒绝近景→协商文字/手部/环境→重新采集 | 保留报道价值并改变镜头语言 | 权利条件直接改变最终作品形式 |
| R09 提前预约并行调查 | 手机预约陈老师→等待期间查公示与短访→到点集中问答 | 提问准备与多任务安排；不浪费整个窗口等待 | 联系顺序与材料整合不同于资料拿到即结束 |
| R10 失约后的独立查证 | 已承诺邮件逾期→催办或自行定位→限定结论 | 可以不等补发，缩小无法证明部分并如实说明 | 应对失约与证据替代，不要求最后一定拿到附件 |
| R11 选题转向 | 初访问题过宽或被拒→公示线索→重定受众→替代采访 | 承认原题不可做并说明转向理由 | 过程变化成为评价证据，初始失败不决定最终低分 |
| R12 发布后修订 | 任一前述路径→语境反馈→回看全记录→重剪或有据回应 | 保留初稿、修订和说明；也容许有证据地维持判断 | 采用现有发布后案例，形成编辑责任与版本判断 |

R12是可叠加的后续策略，不能只靠它把九条基础路线凑成十条。前十一项仍须在同一内容版本中验证可完成性；成功条件不绑定固定台词。学生没有经历的事件保持“未观察到”，不能为了评分自动给所有人补同一段经历。

## 8. 学生界面与教师配置

### 8.1 学生始终知道自己在和谁交谈

人物窗口保留姓名、角色、当前可见活动及连续对话；输入框默认接受一句自然话。话题提示作为可选支架，可询问、可改写、可关闭，不预填一大段“标准通关答案”。打字、等待、收到新消息、对方暂离与重新联系各有清楚状态。

反馈按职业现场呈现：人物直接回应；材料进入采访本；约定进入手机待办；作品建议进入编辑沟通。现场只短暂提示一条有用变化，技术解析状态和重复错误不占据对话主区域。规则无法确定时补问一个与情境有关的问题，保留原输入。

| 工具 | 该突出什么 | 与世界的连接 |
| --- | --- | --- |
| 手机 | 联系人、工作消息、邮件、约定和未完成待办 | 角色在场与渠道可联系是两种状态；消息保留实际到达顺序 |
| 采访本 | 我看见的、谁说的、原始资料、仍有疑问的 | 同一材料只有一个版本引用，保留“教学仿真/公开来源/推测”区别 |
| 现场热点 | 能观察什么、去哪里、对方是否方便 | 随当前有效状态变化；不泄漏隐藏目标和教师剧本 |
| 工作台 | 当前题目、所用材料、正文或剪辑、尚待核实点 | 复用现有作品存储和送审链；避免把内容深化变成全站表单重绘 |

不强制每次对话后都处理一条编辑建议。非阻断建议可以稍后查看；是否必须暂停由真实业务风险决定。学生返回现场时保持人物、输入草稿和消息上下文。

### 8.2 教师编辑的是一节课

初步配置入口建议按“人物、材料、事件、任务”组织：教师能改变人物当前安排与说话方式，选择可供材料，设定一次离场或延误条件，并预览学生能否找到替代办法。先让老师填普通字段，不要求编写Agent提示词、状态JSON或复杂条件表达式。

教师修改形成课程草稿，经预览和发布产生新版本；已开始的学生场次维持原快照。教师端看到每位学生的选题、当前问题、未完成约定、关键行为与作品变化，再决定何时干预。班级管理、形成性模型和正式评分沿用既有D包任务，不在本草案中重复建立第二套后台。

现有六类模型适配器继续保留。自然交谈不是仅打开Live开关：当前对话适配器主要选择已发布规则，需同时改造开场路由、人物观察和表达输出。普通路人、时间推进、发送收据、权限判断与幂等处理继续用程序；需要理解上下文、问答、计划和编辑协作时才调用模型。

同一个人物实例保有身份、当前活动、来源范围、已知事实、未完成承诺和对学生行为的记忆；底层推理模板可复用。人物发言者、执行模板和执行收据必须可区分。模型提出行动，世界引擎确认后更新事实，前端只读取结果。不得让多个独立聊天框各自拥有一套可写世界。

### 9.2 内容数据按使用方式建设

| 数据层 | 需要保存的关系 | 内容生产要求 |
| --- | --- | --- |
| 公开资料 | 发布者→原件→版本→页码片段→可支持的命题 | 补入本轮两份PDF原件；来源日期、适用范围和不确定语气保留，不自动授权所有用途 |
| 教学场景 | 课程版本→人物/地点/材料/事件→可发现条件 | 模拟访谈、公告和平台消息明确为教学编写；不冒充现实采访记录 |
| 行动与作品 | 学生场次→对话/选择/承诺→事件→引用/作品修订 | “问过”不同于“获准”，“承诺发”不同于“已收到”；保留中途转向与未完成事项 |
| 评价与模型 | 具体证据→维度判断→支持/反证→教师决定 | 缺少证据保留未知，模型推断不能反向写成学生事实 |

材料库先沿真实问题补深：公示与更新版本、原始来源与转引、人物完整语境、过程镜头及说明、服务资料、经营合作条件、来源挑战、发布后反馈。现有8份案例材料和11份可处理媒体是优先种子，少量高质量材料经过不同发现方式和判断即可支撑多个分支，不能靠无差别扩充问答条数充量。

课程新版本需保留旧ID映射、来源哈希和场次发布快照；旧存档继续可读，不能把今天的设定直接改进昨天的采访。课程编译和校验应能发现孤立节点、循环前置、全部路线被同一条件锁住，以及宣称送达却没有资料版本的事件。

十名学生独立试用前必须落实稳定学生身份、独立场次及作品归属；不能只换`profileId`共用当前演示世界。所需工作纳入既有DATA-006的优先切片，正式运行库迁移仍按原计划处理。

## 10. 评价与样板课验收

### 10.1 从过程证据理解学生

每条关键观察尽量形成“当时条件→学生选择→理由→使用的材料或作品→后果→是否修正”的链。以下沿用现有六个评价维度，增加有意义的观察机会；具体分档与权重留待专业复核。证据中心设计的研究入口见[ETS报告目录](https://www.ets.org/research/policy_research_reports/publications/report/2003/hsgs.html)，本表是项目自己的课程建议。

| 现有维度 | 新课程中的可观察行为 | 不应作为替代指标 |
| --- | --- | --- |
| 事实与信源核验 | 区分亲历、转引与原件；识别时间范围；对冲突提出后续核验 | 查阅条数、点击所有来源或“核实”关键词 |
| 采访、沟通与知情边界 | 针对对方回答追问，理解拒绝，协商具体记录方式 | 发言长度、固定礼貌声明或拜访人物数量 |
| 编辑判断与独立性 | 解释选题取舍；面对商业资源保持透明判断；选择有证据的主张 | 一律拒绝商户、一律服从编辑或总选系统推荐 |
| 素材权利与内容治理 | 针对文件处理具体许可、署名、使用范围与修订 | 机械勾选同意或把全部素材都删掉 |
| 融媒体作品生产与适配 | 材料服务于叙事，标题与证据一致，媒介选择有理由 | 同时交齐所有格式、字数或镜头数量 |
| 纠错恢复、协作与迁移 | 失约后调整计划、受质疑后核对原记录、说明修订或维持依据 | 首轮零失败、重复道歉或走指定恢复路线 |

所谓“人格模型”宜在产品中具体化为**职业行为画像**：在什么任务条件下表现出什么策略，有哪些支持与反例，尚有哪些看不清。可以展示“这次倾向先查资料、遇到延误后能寻找替代信源”，不能根据一次开场沉默就断言学生内向、能力不足或形成高精度稳定心理人格。教师可追到证据并修订，学生可以解释和申诉。

### 10.2 拟议验收标准

| 验收对象 | 应看到的结果 |
| --- | --- |
| 首次进入 | 至少3个有实际学习价值、可立即行动的入口；至少2条完整策略不依赖门卫引荐 |
| 普通交谈 | 对全部拟开放人物覆盖问候、致谢、含糊来意、改口和拒绝；不会弹出岗位解析技术错误，不伪造许可 |
| 人物一致性 | 不串角色名；对不知道的问题能承认；引用与记忆可追溯，旧承诺影响后续行为 |
| 探索容量 | 至少10种合理策略实际走通；差异涉及选题/信源/取舍/作品修订，而非只有点击顺序 |
| 事件与恢复 | 离场、延误、资料冲突和拒访均有提示及恢复/替代路径；可转向而不清空历史 |
| 时间与消息 | 对话、计划、预约、邮件与截止共用一致时间；刷新不倒退，重复催办不重复生成事实 |
| 评价公平 | 不同合理路径在共同维度上可比较；未经历维度不编造证据，失败后的修正可以被看见 |
| 独立使用 | 不同学生和场次的对话、作品、资料授权与教师反馈不混用 |
| 内容真实性 | 公开事实能定位原件；模拟人物/消息清楚区分；原件未取得和专家未复核如实显示 |

先用确定性策略试走验证可完成性，再安排目标用户试用。程序回归不能代替真实学生的探索分布，也不能替代专业教师对人物和量规的判断。目标师生反馈、十人多路径观察与专家复核分别记录，不用开发者扮演学生来填试用人数。

## 11. 提议中的取舍

下一阶段最值得投入的是“自然交谈＋公共探索分流＋人物计划和资料触发”，随后接入真实待办、角色恢复及作品后果。先把一节课的内容关系做密，再扩充地图和课程数量。

本轮实现采用既有55分钟虚拟窗口、全部十个人物与七个场景；课程参数在代码中独立版本化，不覆盖原V4 manifest。人物、公告、商户预约、居民材料准备与邮件均为教学情境：12份材料包不是12位实际到访者，3组预约也不等于3组成交。两份官方PDF已通过原内容服务摄入，来源和复核情况见[资料登记](../../资料/04-职业教育依据/05-蟳埔样板课调研来源.md)。

教师可视化创作、稳定多学生身份、连续职业画像、作品专业评价深化，以及根据学生成品触发的完整发布后情境仍需继续开发。课程的12种策略是容量与覆盖设计，真实学生的选择分布及教学效果需后续试用，不能由条目数或程序回归替代。
