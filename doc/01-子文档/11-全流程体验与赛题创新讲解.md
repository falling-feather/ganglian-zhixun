## 0. 先看结论

融岗智训不是“看完课程卡后点三个按钮”，也不是“十四个聊天机器人一起给答案”。当前旗舰的正确体验是：

1. 学生以融媒体记者身份进入持续运行的蟳埔采访世界；
2. 学生选择当前可行的岗位动作，并用自己的话说明实际做法；
3. NPC、时钟和受影响的智能体必要子集依据行动质量与当前世界状态回应；
4. 学生可以采纳建议、要求补证或拒绝，错误后可以重做；
5. 事实可信、社区信任、编辑独立、版权风险、时间压力等变量跨轮保留；
6. 学生在独立编辑部真实编写、修订和锁定作品；
7. 高风险公开与发布必须经过教师门；
8. 世界最终结算为可信合作、审慎延误、流量反噬或治理失败；
9. 行动、作品、教师门和世界后果形成能力证据，充分且教师复核后才能更新 LearnerTwin。

学生看到的是岗位现场；教师看到的是业务因果；只有管理员看到 Task、Run、Trace、selected/skipped、失败、降级和执行模式。

## 1. 一分钟启动

### 1.1 最简单的方式

在项目根目录双击：

```text
启动融岗智训.cmd
```

看到终端输出 `status: ready` 后，浏览器打开：

```text
http://127.0.0.1:4173
```

停止程序时回到启动终端按 `Ctrl+C`。

### 1.2 从全新数据开始

如果旧会话已经到结局，或想完整重做一次：

```powershell
.\启动融岗智训.ps1 -Role student -FreshData
```

`-FreshData` 会建立新的演示数据目录，不删除历史数据。不要同时启动两个占用 `3001` 或 `4173` 的实例。

### 1.3 源码方式

进入仓库根目录：

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm start
```

生产启动入口是 `scripts/run-demo-stack.mjs`。开发热更新用 `corepack pnpm dev`；一键启动自检用 `corepack pnpm start:smoke`。

## 2. 三个身份与入口

| 身份 | 默认入口 | 正确关注点 |
| --- | --- | --- |
| 学生 | `/student/courses?profileId=student-unassigned` | 现场、人物、唯一建议、自己的行动、作品与复盘 |
| 教师 | `/teacher/classes?profileId=teacher-class-a` | 业务因果、学生作品、风险门、评价与挑战调节 |
| 管理员 | `/admin/overview?profileId=operator-main` | 六组十四拓扑、真实执行、失败降级、证据和系统质量 |

泉州会话 ID 由服务端在认领或自适应第二场创建时生成，不再依赖固定命名。认领后从浏览器地址栏复制实际 `{sessionId}`，再使用：

```text
/student/training/{sessionId}?profileId=student-unassigned
/teacher/director/{sessionId}?profileId=teacher-class-a
/admin/agents?profileId=operator-main&sessionId={sessionId}
```

第一次体验必须从学生课程空态开始，不要直接跳到深链。这样才能验证“未认领时没有假课程、假任务和假进度”。

## 3. 45—60 分钟完整体验地图

课程世界的虚拟节奏固定为 55 分钟。真实体验者的用时会因阅读、写作和讨论速度而变化，当前尚无真实学生样本证明每个人都严格落在 45—60 分钟。

| 阶段 | 建议用时 | 学生真实工作 | 世界或教学反馈 |
| --- | ---: | --- | --- |
| 认领与读场 | 3—5 分钟 | 从真空态认领泉州课程，阅读岗位、现场与挑战等级 | 创建不可变课程引用和授权世界 |
| 现场准入 | 5—7 分钟 | 向门卫说明身份、用途、公共范围和隐私边界 | 不完整会拒访；补证重做后才放行 |
| 主体采访 | 5—7 分钟 | 与传承人沟通文化主体与劳动生活 | 回应深度、关系和社区信任变化 |
| 主动冲突 | 3—5 分钟 | 处理商户“素材换植入”等利益交换 | NPC 主动发起；接受/拒绝影响编辑独立 |
| 公开边界 | 4—6 分钟 | 与社区受访者协商匿名、删题、撤回和私人范围 | 高风险公开停在第一道教师门 |
| 来源核验 | 6—8 分钟 | 比对原始发布、年份、转引链和研究者证据层级 | 事实可信、证据债和时间压力变化 |
| 编辑部生产 | 15—20 分钟 | 完成七项必交；专题稿至少形成 R1、R2 | 每版有 parent、哈希、证据和送审状态 |
| 发布与结局 | 4—6 分钟 | 提交发布决定并解释风险 | 第二道教师门；世界结算四种结局之一 |
| 评价复盘 | 5—8 分钟 | 查看证据、反思恢复和下一挑战 | 缺证据不出分；充分后才更新 LearnerTwin |

## 4. 学生黄金链逐步操作

### 4.1 真空态与认领

打开学生“我的课程”。新账号应该只看到：

- 标题“尚未认领课程”；
- 一个“浏览课程大厅”按钮；
- 没有课程卡、任务、进度和后台日志。

点击“浏览课程大厅”，找到“泉州蟳埔簪花围非遗专题采编实战”，进入详情并点击“认领课程”。普通学生只能认领记者主岗。

### 4.2 看懂训练页

训练页只有四个业务区域：

1. **现场**：原创蟳埔环境与可互动人物；
2. **世界脉搏**：记者能感知的时间、信任、风险和事实状态；
3. **行动区**：当前服务端允许的几种岗位动作和唯一“执行行动”；
4. **场记本/编辑部**：公开后果、证据与真实作品入口。

页面不会显示 STATE、Trace、Prompt、Provider 或 Token。那些只属于管理员。

### 4.3 先故意做一次不完整沟通

选择“说明采访来意”，输入：

```text
您好，我想进去拍几段素材，之后再跟您说明具体怎么使用。
```

点击“执行行动”。门卫应当拒绝放行，因为记者身份、拍摄范围和私人空间边界不完整。此时选择“要求补充依据”。

预期结果：

- 世界版本不前进；
- 没有假装成功；
- 输入区重新开放；
- 学生可以修正，而不是会话永久卡死。

### 4.4 用专业行动恢复

重新选择“说明采访来意”，输入：

```text
我是课程授权的学生记者，采访范围仅限巷口公共区域；任何住址、未成年人和私人空间都不进入画面。
```

执行后选择“采纳并执行”。门卫应给出“条件准入”，世界信任与采访权限正式变化。

灰色占位文字只是提示，不会自动进入输入框；空输入不能执行。评分和世界后果来自学生真正提交的内容，而不是前端预填标准答案。

### 4.5 处理主动 NPC 冲突

点击“让世界继续演进”。商户吴姐会主动提出以素材换取商业植入。这里可选择：

- 拒绝：保护编辑独立，世界仍继续；
- 要求补证：不接受不透明交换，先确认素材与授权；
- 采纳：可能获得短期资源，但累积商业和信任债。

黄金链选择“拒绝，自己处理”。随后采访传承人，示例：

```text
黄老师，我不想只把簪花围当作好看的视觉符号。请谈谈蟳埔女性、劳动生活与传承习俗之间的文化语境。
```

### 4.6 处理社区公开边界和第一道教师门

世界继续后，选择“协商公开边界”，示例：

```text
阿环您好，我会先说明报道用途；家庭住址、未成年人和私人空间不公开，您可以匿名、删题并随时撤回。
```

采纳建议后，世界不会偷偷公开，而是显示“高风险行动已停在教师门”。此时切到教师端完成第 5 节的操作。

### 4.7 完成双来源核验

教师批准后回到学生端，让世界继续，再完成：

“核验年份材料”：

```text
请逐项比对两份材料的原始出处、发布机关、年份与转引链，并寻找独立来源相互印证。
```

“追问研究者”：

```text
请区分国家级名录、地方标准、口述材料和起源推测各自能证明到哪一步，并标出原始定位与待核边界。
```

这两次行动共同提高事实可信度；只重复“网上都这么说”或要求“先发再核”会产生不同后果。

### 4.8 在编辑部完成七项必交

点击“打开编辑部”。等级 4 黄金链必须锁定：

1. 选题工单；
2. 信源矩阵；
3. 采访提纲与对话记录；
4. 事实核查表；
5. 专题稿；
6. 发布与更正决定；
7. 迁移复盘。

系统还提供素材权利台账、多平台脚本，较高挑战或风险路径会要求更多成果。

每项作品的正确操作是：填写真实字段 → 选择公开证据 → 写版本说明 → 保存 R1 → 检查内容哈希 → 锁定送审。专题稿必须在核验后修改并保存 R2，不能只交一版。

### 4.9 进入发布门

显示“7 / 7 必交已锁定”后点击“进入发布门”，处理责任编辑建议，再切教师端批准第二道门。回到学生现场后，黄金链应显示“可信合作”和“进入评价复盘”。

## 5. 教师导演怎样接力

教师导演页不展示八张空阶段卡，只展示已经发生的业务因果：

```text
世界事件
→ 必要协作集合
→ 岗位协作
→ 学生选择
→ 教师门
→ 世界后果
```

当页面显示“等待教师判断”时：

1. 阅读学生行动与公开业务依据；
2. 确认哪些智能体被选择、哪些被跳过；
3. 查看学生作品送审数量和风险；
4. 选择批准、降低影响后批准或拒绝；
5. 填写真实理由并确认。

批准不会直接改前端卡片。服务端再次校验教师身份、课程哈希、世界版本和待决门，由 `WorldEngine` 原子写回后果。拒绝或漂移不会偷写世界。

教师评价页还可逐维确认或修订证据判断、处理申诉、覆盖 3—7 级挑战并确认成长方案；量规仍标“待专家复核”时，不得把系统建议称为正式专家评分。

## 6. 管理员怎样讲清多智能体

管理员进入“高水平智能体群运行全景”后，先讲三件事：

1. `6 组 / 14 个`是版本化能力拓扑，不是每轮调用数量；
2. “本轮参与”来自真实受影响集合与 DispatchPlan；
3. 管理员可查看完整运行事实，师生端只收业务安全投影。

点击已选中节点，应能查看：

- 为什么被当前事件影响；
- Observation、Task、Run、Intent 与 Resolution 引用；
- 输出哈希、延迟、成本和执行模式；
- 是否失败、降级或重试；
- 允许动作和禁止动作。

点击已跳过节点，应看到跳过理由。真正的技术点不是“十四个图标都亮”，而是无关智能体不被调用、越权输出不能写世界、失败不能伪装为成功。

学生原始行动不会被复制进每个智能体的 Observation。服务端只产生最小安全信号：专业/不完整/风险、命中标准、缺失标准、风险标志、证据数量和公开世界指标。这样既让行动真实影响 NPC，又避免把学生原话和反思扩散到后台群体。

## 7. 四种结局和恢复

| 结局 | 典型累计条件 | 教学含义 |
| --- | --- | --- |
| 可信合作 | 事实可信、社区主体、编辑独立与权利边界均形成闭环 | 专业成功，但仍需复盘取舍 |
| 审慎延误 | 核验和关系基本可信，但主动等待使首个窗口关闭 | 延误不是自动低分，要判断等待是否必要、可并行 |
| 流量反噬 | 短期触达伴随证据债、社区信任债或商业影响 | 复盘最早风险信号和公开更正路径 |
| 治理失败 | 版权、平台或公共安全越过红线 | 教师门可阻断扩散，但不能抹掉此前越界行为 |

四种结局都由累计世界状态结算，不是前端随机文案。自动质量门会在四个独立会话中分别到达四种结局；默认浏览器黄金链展示“可信合作”。

可恢复失败包括：

- 行动信息不完整 → 要求补证 → 重做；
- 建议不可信 → 拒绝 → 自己处理；
- 作品证据不足 → 保存新修订 → 再送审；
- 高风险行动 → 教师修订或拒绝 → 保持零写入或按受控效果继续。

如果发生版本/哈希漂移、越权、Schema 失败或协作失败，页面必须显示安全失败，不能回退成普通成功或普通无匹配。

## 8. 评价、LearnerTwin 与下一轮成长

完成课程不等于自动得到能力分。评价链是：

```text
真实行动、作品修订、建议决定、教师门、世界后果
→ 六维能力证据
→ 缺证据失败关闭或盲化判断
→ 压力等级与透明上限归一
→ 教师逐维终裁
→ LearnerTwin 可变状态
→ LearnerProxyAgent 比较相邻挑战
→ 下一轮成长方案
```

关键边界：

- 证据不足时 `sessionScore=null`，不补一个看似好看的分数；
- LearnerTwin 只保存可变、可证、可申诉的学习状态，不保存固定人格和敏感属性；
- LearnerProxyAgent 不代答、不提交行动、不造证据、不直接评分；
- 3—7 级每次自动最多升降一级，低置信度保持原级；
- 当前可以生成下一轮建议，但还不会自动创建新的授权课程会话。

## 9. 核心技术创新

### 9.1 创新一：事件溯源的职业世界，而非流程课件

课程内容被编译为不可变世界发布：人物、事实、变量、规则、事件、风险门和结局。学生行动经服务端校验后进入世界队列，只有 `WorldEngine` 能写正式状态。NPC、时间和后果可以在学生不点击“下一章”时主动发生。

### 9.2 创新二：受影响集合驱动的高水平智能体群

每个事件先计算受影响对象，再选择必要智能体。每个智能体只有局部视野、职责、允许动作和禁止动作，只能提出 `proposal_only` 意图。管理员能沿 DispatchPlan → Task → Run → Observation → Intent → Resolution 回放真实因果。

### 9.3 创新三：学生自写行动到安全世界后果

学生不是选择标准答案。原始行动先在学生作品域保存，再转换为最小安全信号驱动 NPC；专业、不完整和风险行动会产生不同回应和变量变化。原始话语不扩散给所有智能体，智能体也不能直接把自然语言写成世界事实。

### 9.4 创新四：完成、能力与成长三层分离

课程完成检查“做没做”；能力评价检查“证据能证明什么”；LearnerTwin 只在证据充分、教师复核后更新“下一步怎样练”。这避免用进度条冒充能力，也避免用一次模型判断固化学生人格。

### 9.5 创新五：同一事实的三角色安全投影

学生看岗位现场和一个建议；教师看业务因果和高风险门；管理员看技术运行和失败恢复。三者来自同一会话记录，但披露范围不同。管理员身份可以切换体验，不会因此获得替学生行动或替教师审批的世界权限。

## 10. 对“揭榜挂帅”赛题的回答

项目聚焦融媒体专业群的“采编记者”典型岗位，不用 AI 替学生写答案，而是把真实岗位中的信源矛盾、社区关系、商业压力、版权治理、时间窗口和发布责任变成可运行世界。

| 赛题关注 | 当前旗舰回答 | 尚缺外部证据 |
| --- | --- | --- |
| 真实岗位与任务 | 蟳埔采访、核验、写作、发布与更正形成一条完整工作链 | 一线岗位专家确认 |
| 高水平智能体群 | 六组十四拓扑、受影响集合、局部视野、真实 Run 和权威边界 | 非零 A/B/C 消融与 Live 收据 |
| 友好交互 | 学生只看现场、人物、一个建议和一个主行动 | 真实学生可用性样本 |
| 专业知识与证据 | 来源版本、定位、作品修订和量规均可追溯 | 专业教师内容效度复核 |
| 教学评价 | 缺证据不出分、教师终裁、LearnerTwin 与成长方案 | 一致性、效果和长期学习样本 |
| 可迁移性 | 同一内核保留三门迁移课程占位 | 旗舰 L2 后的深度复刻证据 |

## 11. 八至十二分钟答辩路线

完整体验用于学生训练；答辩只展示代表性纵切：

1. 30 秒：学生真空态，说明未认领就没有假课程；
2. 60 秒：认领泉州，展示原创现场、人物和 4/7 压力；
3. 90 秒：提交不完整门卫沟通，展示拒访与零写入补证；
4. 60 秒：专业重做，展示条件准入和世界变量变化；
5. 60 秒：让世界继续，商户主动发起利益交换；
6. 60 秒：切教师端，展示业务因果和教师门；
7. 90 秒：切编辑部，展示专题稿 R1/R2、证据和哈希；
8. 90 秒：切管理员端，展示 selected/skipped、真实 Run、确定性模式和权威边界；
9. 60 秒：展示四终局测试证据、评价失败关闭和 LearnerTwin 边界。

三十秒开场可这样说：

> 我们不是把课程做成问答页面，而是把融媒体记者的真实岗位变成一个持续运行的职业世界。学生每个行动都会让人物、证据、关系、时间和治理风险发生可追溯变化；事件只唤醒必要智能体，AI 只能提议，世界写入归受信内核，高风险后果归教师。学生最后交付真实作品，系统再从行为和作品证据更新可申诉的学习者模型，为下一轮安排 3—7 级挑战。

## 13. 常见问题

### 13.1 一进学生页什么都没有

这是正确真空态。点击“浏览课程大厅”并认领课程。未认领时不应该显示课程模板、任务或进度。

### 13.2 “执行行动”为什么不可点

必须先选择行动并用自己的话输入实际做法。灰色文字是提示，不是自动答案。

### 13.3 要求补证后世界没有推进

这是正确行为。补证和拒绝本身只记录学生判断，不产生权威世界写入；修正行动后重新提交。

### 13.4 显示“高风险行动已停在教师门”

打开同一 `sessionId` 的教师导演页，阅读业务依据并作批准、修订批准或拒绝。学生端不会偷偷越过教师门。

### 13.5 为什么管理员只有少数节点显示参与

十四个是能力拓扑，不是调用配额。当前事件只运行必要子集，跳过无关调用本身就是架构证据。

### 13.6 为什么显示 `deterministic_demo`

当前没有可验证的真实外部模型凭证和成功收据。确定性 Handler 使用同样的 Task/Run/Intent/Resolution 边界保证可复现，但不得称为 Live。

### 13.7 怎样完全重新开始

停止旧服务后运行：

```powershell
.\启动融岗智训.ps1 -Role student -FreshData
```

等待 `status: ready`，从学生“我的课程”重新认领，不直接打开旧会话深链。
