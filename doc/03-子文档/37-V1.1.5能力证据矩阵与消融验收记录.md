## 1. 验收结论

`AI-006` 已达到“能力主张可映射、三组条件可复现、失败样本不删除、工程门可计算、真实缺失不补造、教师可查看和导出”的原型出口：

1. `gold-readiness/1.0.0` 强制六个且不重复的能力域，每域具有行为、证据、规则、语义建议、教师终审和贡献模板；
2. A/B/C 三组共用同一情境、案例、知识、工具、模型、量规、温度、种子和失败位置，只改变明确的职责、视野、调度和世界门 Profile；
3. A 组保留权威世界门和教师终审，不故意削弱“强模型+工具+门”基线；B 组才按26号标准移除权威世界门；
4. 实验标签、批次和观察元数据不进入模型请求、权限、调度或世界裁决；
5. 确定性合同回放 A/B/C 各十次、各保留一条同位置模型不可用失败，失败运行不补教师分、Token或成本；
6. C 组零私有引用泄漏、零越权正式写入、零权威事实冲突，主要证据覆盖100%、无关调用0%，九项工程门全部通过；
7. 真实 `AgentDispatchPlan / AgentRun / EvaluationCase` 可进入同一观察协议；没有实际观测的语义字段保持 `null`，样本不足时结论为 `insufficient_evidence`；
8. 教师专属页面同时显示合同结果、真实报告状态、结论边界、清单哈希和去标识下载；学生访问返回 `403`；
9. 产品 manifest、不可变情境发布和既有业务世界均未改写。

本版证明的是证据协议、架构开关、失败关闭聚合和展示链可运行。确定性合同中的数值不是实际大模型效果、教师间一致性、学生学习增益、模板最终取舍或正式参赛结论。

## 2. 六域能力证据矩阵

### 2.1 契约结构

`GoldCapabilityEvidenceMatrix` 固定：

```text
能力域
→ 可观察职业行为
→ 白名单证据种类
→ 确定性规则下限
→ 语义评价建议
→ 教师逐维终审
→ 可追踪贡献模板
```

矩阵行数必须等于六，能力域不得重复；行为、证据、规则、语义评价和模板列表均不能为空，`teacherReviewRequired` 固定为 `true`。该结构不允许只写“模型给了一个高分”而没有行为与证据。

### 2.2 六域映射

| 编号 | 能力域 | 主要行为 | 主要证据 | 确定性/语义/教师边界 |
| --- | --- | --- | --- | --- |
| 01 | 选题调研 | 从发布版知识、现场信号和任务约束形成可核验选题假设 | 选题版本、信源计划、引用、采纳/拒绝 | 规则检查引用与节点；语义只评建议质量；教师终审 |
| 02 | 采访核验 | 区分亲历陈述、观察与权威事实并提出补证 | 问题序列、承诺、声明、追问 | 规则检查来源/版本；事实核查给建议；教师终审 |
| 03 | 内容生产 | 从固定材料版本提取观察并保留未核声明 | 材料版本、处理轨迹、修订差异、引用 | 规则检查材料/修订；语义评作品；教师终审 |
| 04 | 治理发布 | 在事实、版权、内容安全和平台规则间作可解释取舍 | 四域Finding、仲裁哈希、教师门、发布后果 | 高风险规则失败关闭；语义分域建议；教师决定 |
| 05 | 协作应变 | 突发事件中识别受影响岗位并形成最小必要协作 | 事件根、受影响集合、交接、任务变化 | 规则检查调度与权限；语义评协作；教师终审 |
| 06 | 复盘迁移 | 基于固定案件解释规则、语义建议与教师终评差异 | 固定案件、逐维分数、覆盖理由、回放 | 分数和证据版本固定；模型只建议；教师终评 |

矩阵当前关联学生辅助、事实核查、材料生产、四域治理、导演/角色协作、三路评价和学习策展等现有模板。它不是以模板数量替代能力证据。

## 3. A/B/C 同条件协议

### 3.1 架构 Profile

| 组别 | 职责 | 上下文 | 调度 | 权威世界门 | 教师最终权 |
| --- | --- | --- | --- | --- | --- |
| A 单体通用 | 一个通用职责处理六域 | 共享视图 | 单体调用 | 保留 | 保留 |
| B 多角色简化 | 多角色提示职责 | 共享视图 | 广播全部角色 | 移除 | 保留 |
| C 完整架构 | 职责分离 | 岗位私有视图 | 严格受影响集合 | 保留 | 保留 |

A 组回答“一个强模型加相同工具和确定性门是否已经足够”；B 组回答“只有多人设、共享视野和广播是否会产生泄漏、漂移与无关调用”；C 组回答“职责、私有视野、受影响集合和世界门的组合是否产生可测优势”。

B 组合同中的越权/冲突“落地”是离线观察计数，不写入真实训练会话。合同执行器不为比较实验放宽生产 `WorldEngine`。

### 3.2 控制变量

协议固定：

- 当前会话钉住的情境发布引用和内容哈希；
- `gold-six-domain-contract-suite/1.0.0` 案例集；
- 相同知识版本、工具版本和可用工具集合；
- 相同确定性模型标识、量规、温度 `0` 和随机种子；
- 每组十次和相同失败重复位置；
- 指标方向、核心指标、阈值与证据等级。

上述字段形成 `controlVariablesHash`；A/B/C Profile 各自形成 `policyHash`。报告拒绝控制哈希、条件码或策略哈希不匹配的观察。

### 3.3 标签隔离

合同模型请求只包含业务案例、授权证据、工具和输出要求，不包含：

- `A / B / C`；
- `conditionCode`；
- `experimentId`；
- `runBatchId`；
- `controlVariablesHash`；
- 观察结果或门状态。

自动化测试逐组序列化请求体并断言上述字段不存在，避免“告诉模型它是完整架构”后再用输出证明完整架构更优。

## 5. 真实会话观测与证据不足语义

`deriveRuntimeGoldObservations` 从实际持久对象读取：

- `AgentDispatchPlan`：条件、策略哈希、受影响集合、选择/过滤和控制哈希；
- `AgentRun`：状态、模型/工具调用、失败码、耗时、Token和成本；
- `EvaluationCase / EvaluationProposal / EvaluationArbitration / TeacherAssessmentReview`：固定案件、建议和教师逐维决定。

只可派生已经存在的事实。以下字段若没有专门观察或人工标注则保持 `null`：

- 私有引用是否泄漏；
- 是否发生越权正式写入；
- 是否形成权威事实冲突；
- 证据是否有效覆盖结论；
- 调用是否与当前事件无关；
- 教师是否因模型问题逐维修订。

聚合器把 `null` 计为未观测，不计为零。A/B/C 任一组未达到十次，或核心语义不足时，`observedSessionReport` 不形成绿色结论。教师端显示“真实会话观测尚未达到 A/B/C 门槛”。

该语义防止三类伪证据：

1. 把“没有日志”写成“没有泄漏”；
2. 把“任务被过滤”直接写成“该调用无关”；
3. 把确定性合同分数复制到真实模型失败运行。

## 6. 去标识评价导出与教师裁决

### 6.1 导出字段

`GoldDeidentifiedEvaluationExport` 只保留：

- 稳定案件替身与内容哈希；
- 情境发布替身；
- Rubric版本/哈希；
- 逐维最大分、规则分、模型建议分、教师最终分；
- 证据覆盖数、分歧与覆盖状态；
- 案件是否已完成教师终评。

案件和证据标识经稳定哈希生成替身，不能从导出定位原始会话对象。

### 6.2 明确排除

下载不包含：

- 会话、学生、教师、评审者和行动者身份；
- 内部备注、公开反馈原文和覆盖理由原文；
- 原始案件ID、证据ID和供应方请求ID；
- Prompt、完整聊天、原始材料和私有记忆；
- Cookie、CSRF、密钥、租约、幂等键或恢复私有载荷。

教师仍是最终裁决者。导出只读取既有终评，不生成、修正或覆盖教师分数；没有教师终评的案件保持未完成。

## 7. 教师 API、实验台与深链

### 7.1 API

```text
GET /api/sessions/:sessionId/gold-readiness?bindingId=:teacherBindingId
```

API 先执行现有 Cookie、成员关系、会话和教师绑定校验，再读取授权投影、派发计划、运行和评价对象。学生绑定返回 `403`。响应由 `GoldReadinessWorkbenchSchema` 复核。

工作台清单包含：

- 契约版本；
- 当前情境发布引用和内容哈希；
- 控制、协议、矩阵和报告哈希；
- 生成命令说明；
- 可选 Git 提交绑定。

只有运行环境注入合法四十位 `BUILD_GIT_COMMIT` 或 `GIT_COMMIT_SHA` 时 Git 绑定才出现；开发环境未注入时显式为 `null`。本版尚未把运行下载固化为 `artifacts/gold-readiness/manifest.json`，该版本化证据目录由 `QA-002` 在最终提交哈希确定后生成。

### 7.2 教师实验台

教师导航新增“国金证据”，页面展示：

- 六域、合同运行、失败样本和工程门 KPI；
- A/B/C 架构说明和分组指标；
- 九项门的实际值、阈值和状态；
- 真实会话报告、去标识案件和教师终评数量；
- 排除敏感字段说明；
- 情境、报告和 Git 绑定；
- 六域矩阵；
- 去标识 JSON 下载。

首屏固定显示：

> 当前绿色结论只代表工程合同通过，不替代真实模型、教师一致性或学生学习成效。

该边界同时进入下载数据，不能只在页面脚注中表达。

### 7.3 深链修正

教师 `?view=teacher&section=readiness` 在认证回调后保持 `readiness`，不再被统一重置为 `director`。修正删除了对所有非情境教师栏目的错误回退，因此证据回放、运行调试、评分复核等合法教师深链也保持当前栏目。学生教师深链回退规则未放宽。
