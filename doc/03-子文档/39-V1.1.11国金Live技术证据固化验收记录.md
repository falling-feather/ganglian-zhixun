## 8. V1.1.14 黄金路径架构修复与真实界面验收

### 8.1 问题与根因

正式黄金演示准备阶段首次以“全新发布版 + 全新生产会话 + 真实异步工作器”连续执行总编、记者、教师和责任编辑动作。素材处理虽然技术完成，但教学导演与情境导演各有任务以 `invalid_world_action` 失败，暴雨候选没有出现。持久任务与世界日志复核后确认根因不是普通状态版本竞争：

1. `request_media_processing` 按固定材料的角色白名单同时生成任务事件、过程证据和节点推进；
2. `media_processing_requested` 应保持受限，但调度器也会依据后两项安全进展建立双导演任务；
3. 后两项继承同一材料白名单，固定导演无法读取自己的触发事件，世界边界因此拒绝执行；
4. 初始 `route-source-scaffold` 候选的世界前置状态已经变化，却仍以 `pending` 占据教师待审队列，新的情境导演路线被重复候选门拦截。

这说明问题同时位于权限传播和候选生命周期，不应通过放宽全部材料权限、让调度器忽略读取失败或在前端隐藏旧候选解决。

评分者、案例或方差不足时指标返回 `insufficient`，不会填0或伪造“通过”。候选可采纳度、回答质量和正式学生能力分始终是三个不同语义，该工作流不修改世界事实、学生成绩或教师终评。

收据只保存这些聚合值、标准结果/退出类别、事件快照哈希、幂等哈希、冻结时间和收据哈希。原始事件 `text / payload`、学生自由文本、完整聊天、私有记忆、真实姓名、Cookie、密钥和原始幂等键不进入研究状态或JSONL。退出类别只有参与者退出、撤回同意、其他退出、超时、服务降级、卡住、人工中止和其他技术失败；不提供可能泄露身份的自由文本理由。

## 20. V1.1.26 试点分析冻结与可复核报告工作流

### 20.1 验收结论与主张边界

`QA-003 / V1.1.26` 以 `V1.1.26 QA feat(pilot-analysis): 建立试点分析冻结与可复核报告工作流（QA-003）` 同步实现与文档，建立从采集前冻结到采集后不可变报告的失败关闭主链：

```text
采集前冻结收据 + 协议/量规/等价任务/分配快照
→ 试点创建时绑定固定分析计划
→ 每个预登记运行形成完成/退出/技术失败收据
→ 所有教师配置/干预/终评计时关闭
→ 样本流转保留全部退出、技术失败与缺失
→ 仅两期均完成者进入完整配对，不插补
→ 生成设计诊断、配对指标、负担与稳定性摘要
→ 固定来源快照、限制、主张边界与报告哈希
→ 冻结后幂等且不可变
```

本次关闭的是“采集前设计虽然已冻结，但采集结束后仍可临时改变纳入样本、缺失处理、分析口径或报告来源”的架构缺口。它没有生成专家、教师或学生样本，没有执行统计推断，也没有形成学习增益、因果效应、统计显著或可推广结论。

### 20.3 分析冻结、样本流转与不插补

`GoldPilotStudyCoordinator.freezeAnalysisReport()` 要求：

1. 试点具有固定分析计划、任务分配和设计来源绑定；
2. 预登记的每个运行槽都已有完成、退出或技术失败收据；
3. 所有教师负担计时段均已关闭；
4. 当前来源修订、收据和报告哈希不变量仍成立。

报告保留登记教师/参与者、预期/已结案/未结案运行、完成/退出/技术失败运行、完整/不完整配对、分析纳入运行，以及 `completed / participant_withdrawal / consent_revoked / other_withdrawal / timeout / degraded_service / stuck_session / manual_abort / other_technical` 九类计数。只有两期均为 `completed` 的参与者进入配对差值；退出、技术失败或只完成一期者不被删除，但不插补、不把缺失当零。两条件普通汇总均值也只使用完成运行。

报告冻结后，重复请求返回同一 `reportId / reportHash`；继续新增运行收据、计时或改写来源会被状态机拒绝。

### 20.4 报告内容、状态与敏感字段边界

不可变报告输出：

- 四个“条件顺序×任务顺序”单元的登记/完整配对数、最大登记不平衡和登记平衡状态；
- 条件×任务、时期×条件的登记/完成运行诊断；
- 15项完整配对的课程平台均值、双维度均值、差值均值/中位数/最小值/最大值；
- 配置、干预、终评三类教师计时的已关闭段数、总时长、均值和中位数；
- 两条件完成运行中的失败、降级、超时、人工接管和恢复汇总；
- 采集前绑定、协议、参与者/任务分配、运行收据和教师计时的来源快照哈希；
- 缺失目标、四条固定限制、主张边界、来源修订、冻结时间和 `reportHash`。

缺少3名教师、20个完整配对、登记四格平衡或任一教师负担阶段时为 `exploratory`；全部齐备时仅为 `target_ready_for_descriptive_comparison`。状态名称有意不包含“passed”“effective”或“significant”。

报告不含教师/参与者别名、运行会话ID、原始聊天、录音、真实姓名、联系方式、自由文本退出原因或私有记忆。`studyId`、规范版本、聚合计数和不可逆哈希用于复核，不用于还原身份。
