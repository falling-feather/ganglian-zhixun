# 浙江传媒学院专业特色与项目转化

> 目的：说明“浙传优势如何进入产品”，而不是把学校介绍堆进申报文案。浙江传媒学院是传媒类本科高校；本项目服务职业教育，不能把两者身份混写。

## 1. 采用的官方来源

| 来源 | 采用结论 |
| --- | --- |
| [浙江传媒学院：创新传媒人才培养路径](https://www.cuz.edu.cn/info/1451/218861.htm) | 当前痛点包括新闻理论与技术应用脱节、与真实生产场景存在差距；学校提出新闻采编、技术应用、融合创新“三维核心能力” |
| [学校简介](https://www.cuz.edu.cn/xxgk/xxjj.htm) | 新闻传播、视听制作、工程技术交叉，拥有电视编辑与导播国家级实验教学示范中心和大量产学研实践基地 |
| [“传媒教学肯定要紧跟时代”](https://www.cuz.edu.cn/info/1451/45311.htm) | 人工智能新闻微专业由新闻传播与媒体工程协同，课程围绕真实应用、人机协同、伦理边界和行业导师实践设计 |

## 2. 转成产品能力，而不是宣传语

| 浙传特色 | 产品中的对应实现 | 仍需补强 |
| --- | --- | --- |
| 新闻采编能力 | 采访、事实核查、信源分级、稿件修订、发布后更正 | 在教师评价页把对应证据明确汇总为“采编基本功”维度 |
| 技术应用能力 | AI 建议、多模态作品、来源与权利台账、模型候选和降级 | 让学生感受真实工作工具，不向学生暴露后台 Trace；补一个星辰工作流交付实例 |
| 融合创新能力 | 多平台脚本、图文音视频成果、运营反馈和跨角色协作 | 把平台适配和受众反馈对作品的后果做得比“提交另一个模板”更明显 |
| 真实项目制 | 蟳埔 55 分钟持续世界、人物冲突、教师门和作品 | 用目标专业教师访谈说明痛点来源，不能只靠团队内部仿真设定 |
| 跨学科协同 | 传媒规则、智能体工程、权利治理和评价证据共同运行 | 在能力图谱中区分专业判断、技术运用和融合创新，避免统称“综合能力” |

## 3. 应形成的浙传辨识度

下一轮页面或报告不应再增加校史介绍，而应在同一学生证据上输出一张“三维能力矩阵”：

```text
新闻采编基本功
  ├─ 信源核验
  ├─ 采访与公共利益判断
  └─ 稿件事实与更正
技术应用能力
  ├─ AI 建议的核验与边界
  ├─ 多模态素材处理
  └─ 来源、版权与生成标识
融合创新能力
  ├─ 跨平台叙事
  ├─ 受众与运营反馈
  └─ 多角色协同和发布后响应
```

每个节点只引用已经终裁的行为、作品和后果证据。矩阵既是学生成长视图，也应成为专业负责人观察课程缺口的输入。这样才能把浙传的专业特色变成可运行方法，而不是背景标签。

## 4. 不采用的做法

- 不宣称浙江传媒学院已经正式部署、认证或验证本系统；
- 不因为学校拥有大量实践基地就伪造本项目的校企合作证据；
- 不把 AI 生成效率当作传媒能力，事实、伦理和人工终裁仍是前置条件；
- 不用学校新闻稿替代职业院校专业标准、职业标准或目标用户访谈。
