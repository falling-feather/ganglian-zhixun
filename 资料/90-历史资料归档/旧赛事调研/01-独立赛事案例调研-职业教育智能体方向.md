# 独立赛事案例调研：职业教育智能体方向

整理日期：2026-06-24

本文用于纠正前一版报告中过度沿用《越韵智传》附件样本池的问题。后续报告中的“往届获奖作品分析”应以本文件为基础，而不是照搬同学项目中的获奖案例表。

## 一、调研范围

本轮调研不再只看某一份企划书中的样本，而是从三类赛事和官方材料中提取规律：

1. 挑战杯：关注学术科技作品、硬科技、原始创新、完整技术链条和可验证成果。
2. 中国国际大学生创新大赛（原互联网+）：关注真实产业需求、产品化、商业模式、团队落地能力；其中职教赛道尤其重视职业院校、产业技能和真实应用。
3. 中国青年科技创新“揭榜挂帅”擂台赛：关注发榜单位真实需求、擂台比拼、原型展示和成果转化。

## 五、重新归纳的评审偏好

本轮独立调研后，不应再使用“获奖项目 100% 有 AI 生图”这类过于武断的结论。更稳妥的归纳如下：

1. 评委偏好“真实问题被清楚定义”的项目。  
   好项目通常能说明谁遇到了什么问题、为什么现有方法不够、项目如何改变流程。

2. 评委偏好“技术链条完整”的项目。  
   不是一个聊天框，而是数据、知识、模型、流程、交互、评价、反馈构成系统。

3. 评委偏好“可展示、可验证、可量化”的项目。  
   可展示不等于必须生图，也可以是原型界面、任务流程、能力画像、测试报告、真实试点反馈。

4. 职教赛道偏好“产业/岗位/技能”表达。  
   对职业教育项目来说，讲清楚岗位工序、技能评价和真实训练，比讲宏大教育理念更重要。

5. 揭榜挂帅偏好“对发榜需求的精准响应”。  
   我们要让评委一眼看出：这个项目正是为“职业教育高水平专业群建设的教学实训与岗位技能智能体开发”而生。

6. 与媒体相关的 AI 项目已有竞争者。  
   “AI 智媒”“视频审查”“影视工具”都不是空白方向。我们的差异应落在职业教育训练体系：岗位工单、智能体协作、证据链评价、专业群反馈。

## 六、对两个方案的修正判断

### 6.1 方案一：融媒职训 Agent Studio

更适合作为主方案。理由是它直连赛题中的“高水平专业群建设”和“智能体开发”，可把竞赛偏好的“真实问题、技术链条、量化验证、落地场景”完整串起来。

需要强化的点：

1. 少讲“平台宏大”，多讲“教师如何把一个岗位变成实训工单”。
2. 把内容治理作为样板岗位群，而不是泛泛的融媒体方向。
3. 用 4 个可演示工单证明系统有效。
4. 准备职业院校教师访谈或试用反馈，哪怕是小样本。

### 6.2 方案二：智审片场

适合作为展示型样板方案。理由是它视觉表达强，能体现浙传影视特色，也能与职教赛道中已有的影视、视频审查、AI 智媒项目形成关联。

需要强化的点：

1. 不要把它写成影视生成工具。
2. 必须说明片场只是职业岗位训练媒介。
3. 把“审片”从工具能力扩展为教学实训中的事实核查、版权合规、平台审核和过程证据。
4. 与已有“AI 视频审查安全卫士”类项目拉开差异：它们偏产业安全工具，我们偏职业教育实训系统。

## 七、下一步资料缺口

正式申报前建议继续补齐：

1. 职业院校数字媒体、融媒体、网络新闻与传播相关人才培养方案。
2. 2 到 3 位职业院校教师访谈纪要。
3. 融媒体编辑、内容审核、AIGC 运营、版权审核等岗位 JD。
4. 平台社区规则、AIGC 标识规范、版权合规案例。
5. 一个可运行或可点击的原型，至少展示教师生成工单、学生完成任务、智能体审核、教师复核、专业群反馈五个环节。
