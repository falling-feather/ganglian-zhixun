# 融媒体岗位实训访谈与试用记录

更新日期：2026-09-11。用途：为岗链智训收集真实职业教育需求和具体试用反馈，对应XA-202603。当前没有在本文填入真实受访结果；软件模拟身份不属于受访者。

## 1. 找谁、核对什么

优先邀请高职融媒体技术与运营、新闻采编与制作及相关数字媒体方向的专业教师、实训教师和学生。企业导师可来自融媒体中心的采编、审核、视听制作或内容运营岗位。专业群负责人用于核对群与岗位关系，不能代替具体学生操作反馈。

如指导教师来自本科院校，准确记录其身份；专业指导意见可以采用，不能改标为职业院校师生试用。正式专业群、院校合作及真实企业委托必须有对应材料，不从项目名称推定已成立。

## 2. 开场与授权

说明本项目用仿真采访场景训练采编岗位：教师给出委托，学生调查、核验并形成作品，系统呈现依据与缺口，教师复核。询问是否愿意试用、是否允许记录原话、可公开到什么范围。受访者可拒绝记录或提出更正；不预设其必须给出正面评价。

不采集学号、身份证或不必要的联系方式。必要身份只记录专业、年级/任教角色及匿名编号；实名或院校名称仅按本人/单位允许范围使用。

## 3. 先了解实际工作

1. 最近一次真实采编或教学任务是什么？谁提出委托，要交付什么、服务谁、多久完成？
2. 学生在哪个具体环节最困难：形成选题、接触受访者、追问、核对来源、处理许可、编辑、多平台适配，还是更正交接？请给一个例子。
3. 您依据什么判断学生掌握了技能？哪些作品或过程证据最有用？
4. 哪类AI建议可能使学生误判？哪些工作可交给系统提示，哪些必须由学生或教师决定？
5. 当前任务设计、资料更新或批改耗时在哪里？如愿意估计时间，请同时说明任务规模和估计依据。

## 4. 具体试用任务

记录实际测试版本、入口、场次ID、日期和所用设备。生成发布功能按当时实际可用状态测试；尚未实现项标未测，不由口述演示补成已用。

| 角色 | 操作任务 | 观察与追问 |
| --- | --- | --- |
| 教师 | 输入一份具体岗位委托，核对生成的任务、依据、学习目标及成果要求，修改后发布 | 哪一步不符合真实教学？哪些知识映射错误或多余？修改花了多少时间？ |
| 学生A | 选择人物或技艺切口，完成实际问答、记录边界、核验并保存作品 | 是否知道下一步能做什么？哪句话误解了你？请指出原话和人物回应。 |
| 学生B | 从公开资料或游客服务问题起步，不把居民采访作为必经门 | 是否能走出不同路径？哪里必须等待？材料送达和使用状态是否清楚？ |
| 教师 | 对照学生作品片段、实际行为与系统反馈，给出具体意见 | 哪条判断有依据、哪条不成立、还缺什么证据？不能只评价界面好不好看。 |
| 师生 | 复核后进入下一轮训练，核对任务条件变化 | 改变是否针对实际缺口？是否能观察学习者下一次的表现？ |

两至三名目标师生分别留下简短文字或视频反馈；人数、身份和意见必须真实。一次工程自测、多个演示账号或同一人的多次点击不能当作多名目标用户。

## 5. 不诱导的反馈问题

- 请指出一处有帮助的具体功能，以及它帮助了哪项采编判断。
- 请指出一处错误、误导或不符合教学实际的内容；若没有观察到，也可直说未发现。
- 如果去掉这个功能，你原来怎样完成任务？请描述过程，暂不要求给系统打分。
- 您是否愿意在类似任务中再次使用？原因是什么？有哪些必要条件？
- 还有哪些过程证据或教师控制不能缺少？
