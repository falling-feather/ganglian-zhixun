生成约束包括：成年人物、完整身体、各格不重叠、自然工作姿态、透明通道；场景保留真实比例和可安放人物的空间，避免嵌入品牌与宣传文字。PNG 透明通道和实际场景合成已经检查，图集通过渲染器取相应单元，不另存重复裁切副本。

三张界面概念图保存在 [doc/image](../../../doc/image) 中，由 [17号架构说明](../../../doc/01-子文档/17-V3交互骨架与内容架构.md) 引用；概念图与运行截图分别标注。教师自行上传的立绘进入所选课程的素材记录，须填写使用说明，按不可变原件保存。
