# 融岗智训流程演示视觉规范

## Style Prompt

沿用“融岗智训”平台本身的职业教育控制台风格：深海军蓝承载品牌与章节信息，青绿色只用于关键动作和进度提示，浅灰蓝作为辅助信息。画面应像一份清晰、可信、可操作的产品演示，不做炫技式宣传片。

## Colors

- `#071827`：品牌深海军蓝，片头、片尾和说明卡底色。
- `#0D2B3A`：次级深蓝，用于卡片边界和装饰层。
- `#24C7C9`：唯一主强调色，用于动作编号、进度线和状态点。
- `#F2F7FA`：主文字与片头标题。
- `#9AB5C2`：辅助说明和时间标签。

## Typography

- 标题与中文正文：`Microsoft YaHei`，标题 900，正文 350–400。
- 步骤编号和时间信息：`Cascadia Mono`，500–700，并使用等宽数字。
- 标题不小于 60px；说明正文不小于 20px；状态标签不小于 16px。

## Components

- 片头/片尾：全画幅深色画布、局部径向辉光、细线网格。
- 章节说明：右下角半透明深蓝卡片，包含角色标签、步骤标题、一句指引。
- 进度线：青绿色细线从左向右展开，不使用循环动画。
- 视频主体：完整保留 Web 原始录屏，不裁掉平台导航与身份切换区。

## Motion

- 中等能量、技术说明型节奏。
- 片头到录屏、录屏到片尾使用 0.5 秒模糊交叉淡化。
- 章节卡使用不同层级的横移、上移和透明度进入；不使用弹跳或高频闪烁。
- 所有动画由同一条可寻址 GSAP 时间线驱动。

## What NOT to Do

- 不使用紫蓝霓虹、渐变文字、发光描边或高频故障效果。
- 不遮挡 Web 端主操作区超过画面的 20%。
- 不把管理员日志文案带入学生或教师章节说明。
- 不使用小于 16px 的文字，也不依赖颜色单独表达状态。
- 不添加旁白、背景音乐或与真实操作无关的宣传口号。
