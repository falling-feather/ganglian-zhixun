# 详细全流程演示脚本

总时长约 7 分 14 秒，画面主体为真实 Web 交互录制，无旁白与背景音乐。

1. 片头（0:00–0:06）
   - 标题：融岗智训｜课程到终评详细全流程。
   - 说明：选课、岗位协作、治理、R1/R2、教师终评与学生反馈。
2. 选课与进入课程（0:06–0:19）
   - 先展示未认领/课程大厅，再进入已认领课程工作台。
3. 岗位协作与角色智能体（0:19–1:15）
   - 责任编辑向总编确认门禁和终审承诺。
   - 切换记者岗位采访非遗流程并追问客流边界。
4. 事实、版权与平台门禁（1:15–2:58）
   - 教师批准客流更正。
   - 版权方拒绝超范围商业使用，教师批准争议事件。
   - 平台运营要求人工复核，学生最终选择暂缓发布。
5. 异步处理与四域治理（2:58–4:49）
   - 图片理解与合规检查仅形成待复核观察。
   - 四域并行治理产生阻断，教师驳回。
   - 学生替换为合规材料后重做，教师批准精确仲裁。
6. R1 / R2 成果修订与提交（4:49–5:55）
   - 保存不可变 R1。
   - R2 替换未授权材料引用，显示 R1→R2 差异并提交精确版本。
7. 教师终评与学生反馈（5:55–7:07）
   - 评价智能体提出四维建议，教师填写反馈并锁定 92.2 分。
   - 学生查看四维反馈、可见证据与实际/替代策略复盘。
8. 片尾（7:07–7:14）
   - 结论：真实行为、门禁纠错、精确版本和可追溯评价已形成闭环。
