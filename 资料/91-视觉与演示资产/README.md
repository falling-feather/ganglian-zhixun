# 视觉与演示资产

本目录保存用户视觉参考与既有流程演示工程，不属于四类活跃研究资料。

- `课程视觉参考/`：两版智能体情境游戏概念图；用于学生现场、NPC 互动、事件后果和教师导演台的视觉基准；
- `档案式首页参考/`：2026-09-12用户提供的五张图片及后续教师页参考；原始方向与反馈保留在[项目规划](../../doc/02-项目规划.md#21-档案首页视觉反馈2026-09-13)，实现见[17号文档](../../doc/01-子文档/17-V3交互骨架与内容架构.md)；
- `采访工作台参考/`：用户提供的历史工作台截图；已实施的私人笔记和作品边界见[开发者文档](../../doc/01-开发者文档.md#6-当前评价实现程度)；
- `流程演示/`：既有录屏、成片和 HyperFrames 工程；本轮只迁移路径，未改写用户内容；
- HyperFrames 自动备份位于其工程 `.hyperframes/`，继续被 Git 忽略。

引用这些资产时应指向具体文件和使用目的；不能仅因图片存在就宣称页面已实现或浏览器验收已通过。
