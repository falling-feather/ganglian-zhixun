## 1. 演示口径

- 产品能力基线：`V2.4.7 / QA-012`。
- 工程与资料治理基线：`V2.4.8 / OPS-001`。
- 本次文档与演示交付：`V2.4.9 / DOC-011`，不新增产品能力。
- 权威链：课程发布与认领 → `SessionExperienceDescriptor` → 学生动作 → `WorldEngine` 事件 → 受影响集合 → `AgentTask/AgentRun` → 学生选择/教师门 → 世界后果 → 作品与证据 → 六维评价 → 教师终裁 → 学习者数字分身 → 双同意第二场。
- 模型口径：截图使用 deterministic 模式，证明完整业务合同与失败关闭可以复算；不冒充 DeepSeek 或讯飞星辰 Live。

## 3. 必须同步呈现的诚实边界

1. 当前只有门卫、传承人、商户三名关键人物具备完整受约束多轮 Episode；不是十名 NPC 都能无限长聊。
2. 媒体评价已读取真实图像预览、音频频谱与视频关键帧；没有 ASR，不把频谱说成语义理解，也不把三帧说成连续视频理解。
3. 36 条旗舰知识仍为 `pending_expert_review`；代码不能伪造专业教师签字。
4. 受控 DeepSeek 合同冒烟已经通过，但本次截图使用 deterministic；讯飞星辰尚无已发布工作流 ID/ServiceID 和真实收据。
5. A/B/C 消融框架已实现，但真实观察为 0 时只能显示“证据不足”，不能宣称多智能体已经优于基线。
6. 课程进度与作品汇总的旧聚合尚未完全消费 V4 工作台证据；当前权威可见结果以 V4 编辑部、评价页和管理员证据页为准。
7. 1281 项非 Live 自动化、13/13 fresh Chromium 黄金链证明工程一致性，不证明教学效果、专业量规效度、获奖结果或真实用户偏好。
