## 本轮呈现

依据[02号参考稿](../../2026-09-14-教师首页白色档案/README.md)及用户后续反馈制作。保留低视角、白色薄档案和侧露姓名，布局已调整为**前排加后三排**；档案行从屏幕外进入，向右下连续移动，移出后在屏幕外回接。后一轮反馈优先于参考图原先的单排留白。

悬停显示姓名、当前课程与状态，选中档案停稳，后续档案沿学生端原有的减速与间距避让规则排队，其他行继续移动。点击抽出白色档案，关闭后归位。姓名以贴图直接绘制在对应三维封面上，按正确宽高比排字，后排留出完整姓名的显示空间。

可操作内容：档案悬停、抽出／收回、姓名搜索定位、展开目录、键盘选择、减少动态效果，以及班级查找、课程导演和教学资料页。所有内容仍在独立样机中，未接入真实后台。

## 班级与教师工作页

一列档案固定对应一个示例班级；切换只改变列的空间顺序，不改变学生与班级的绑定。首页班级按钮触发约1.25秒的三段动画：前排列向两侧让开、目标班级整列前移、其他班级在后方归位。快速连续选择会保留最后一次请求；减少动态模式直接完成定位。

首页搜索和目录按当前班级筛选。课程导演与教学资料共用这个班级选择，离开档案页时停止三维演算。

- [课程导演](http://127.0.0.1:4185/#director)：本地人物草稿、默认节点选择及说明、人设／知识／关系／立绘预览、暂存配置和发布范围预览。
- [教学资料](http://127.0.0.1:4185/#materials)：按班级显示资料、名称查询、来源片段示例、选中文件及使用说明的本地预览。
- 草稿只保留在当前页面内存中；切换页面保留，刷新重置。发布预览不会给学生开课，文件选择不会上传原件或调用模型。

配色以白色档案、冷灰蓝背景、较深侧边和深色文字形成层次；前排班级用黄色标记，其他班级采用蓝色标记。普通工作页使用同一套白色面板、蓝色选择和黄色主要操作。

## 启动与构建

复用项目现有 Node 与 `apps/web/node_modules`，不新增独立依赖清单或锁文件。在本目录执行：

```powershell
.\启动教师首页.ps1
```

或者：

```powershell
node ../../../apps/web/node_modules/vite/bin/vite.js --config vite.config.mjs
node ../../../apps/web/node_modules/vite/bin/vite.js build --config vite.config.mjs
node ../../../node_modules/typescript/bin/tsc -p tsconfig.json
node ../../../node_modules/vitest/vitest.mjs run motion.test.ts class-motion.test.ts --config vite.config.mjs
```

端口固定为4185，冲突时明确退出，不自动占用其他项目端口。按Ctrl+C停止。构建与缓存均写入项目既有的 `.local/teacher-home-prototype/`。

档案宽高、循环槽位、减速避让、30FPS绘制上限、品牌标记与纸面素材均复用原程序。教师样机只调整行列、低视角、白色材质、姓名和外层UI；没有复制一套学生端排队算法。动画数据留在渲染器中，不通过React逐帧重绘整页。

本样机用四个完整循环行及252个占位编号验证运动与查询，**不是实际学生数量**。循环保持编号与档案绑定，搜索不会把姓名替换到另一个记录上。实际数据接入和真实名单规模处理留到用户确认前端后开展。
