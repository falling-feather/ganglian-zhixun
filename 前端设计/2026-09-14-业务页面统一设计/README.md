# 学生与教师业务页面 · 统一设计稿

日期：2026-09-14；入口状态核对：2026-10-17。本文保留全套静态设计方案及当时范围。后续已按用户授权将主题与共享控件接入正式程序，实际变化和待验收项见[FE-022](../../doc/02-项目规划.md#3-当前任务)与[交付复查](../../doc/01-子文档/19-V3成品交付与验收.md#v301-recheck)，不以设计图片推定所有页面均已验收。

## 审阅入口

打开 [设计稿审阅页](index.html)，可按学生业务页、教师工作台与通用规范浏览，点击图片放大。每张图片均有编号，可以直接反馈“S04 的资料条目……”或“T06 的评阅区域……”。

本轮按用户最后澄清的范围，处理学生作品、数字资料、评价等常规业务页面及相应教师工作台。已建立方向的档案馆首页和沉浸式采访现场不属于本次重绘。管理端、课程内容重编和新增业务能力也不在本次范围。

## 已确认方向与待审内容

已确认的视觉方向：黑色主色、白色文字、黄色与蓝色点缀、现代无衬线字体。用户已原则认可这套方案，但明确要求暂不实施；图中的具体字段与辅助控件仍需按下方业务映射处理，不能把设计认可记作功能已实现。

| 项目 | 提案值 |
| --- | --- |
| 背景 | `#090B0E` |
| 面板／输入 | `#15181D`／`#1C2026` |
| 正文／辅助文字 | `#F5F7FA`／`#AFB7C2` |
| 分割线 | `#303640` |
| 黄色 | `#F2C550`，用于主要操作与必要提醒 |
| 蓝色 | `#74B3FF`，用于链接、当前选择与键盘焦点 |
| 字体 | 现代无衬线；实现时优先系统字体，中文可用 Microsoft YaHei UI／PingFang SC，避免新增首屏字体下载负担 |
| 字号 | 页面标题约32px、分区标题24px、正文16–18px、辅助文字14px；图像尺寸不等于CSS像素 |
| 控件 | 细边框、6–10px圆角、清楚的悬停与聚焦状态；触控目标不小于44px |

延续档案语义的是文件页签、留白与细分隔线；业务页面以阅读和操作为主，不增加动态三维背景。

- 页面内样例作品、人物、日期、数字和评价维度文案只说明排版，不代表真实学习数据或已成立的教学结论。正式字段、课程小节、评价维度、格式支持和操作权限仍以原有实现为准。
- 生成图偶尔出现的辅助图标、拖动柄、全屏、复制或展开控件不自动变成新增功能需求；实施前逐项映射到已有操作，未确认的新增能力不接入。
- 单人在学约束、作品版本与送审、教师终裁、私人笔记权限、模型检索授权及课前发布语义保持不变。
- 设计通过后再统一学生与教师的主题变量、共享组件和必要的布局规则。避免逐页追加互相覆盖的硬编码颜色，也不把主题变更扩展为课程或评分重构。
- 本轮没有构建或测试新的程序界面；检查的是图稿覆盖、可读性、文件完整性与文档结构。之后的正式改动另行验证真实流程和窄屏。
