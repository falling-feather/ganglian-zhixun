# 黑色档案首页 · 复刻规格

2026-09-13，FE-020。用户已确认三态图并要求精细复刻。实现位于正式 apps/web；本目录保存设计与比对，不再生成另一套业务程序。当前为工作区实现，尚未发布新版本。

## 1. 固定的视觉与交互

- 按1672×941原稿视口比较；黑色档案覆盖整个画面，顶部和边缘保留克制的导航、搜索、筛选与展开入口。
- 每份档案是薄的硬质几何体；按最新反馈逐行沿画面右下→左上、左上→右下反向连续流动，移出一端后从另一端接续，节奏一致。鼠标附近减速至停止，远处继续。移开后平滑恢复。
- 降低约一半档案密度，拉开间距，保持满屏覆盖与单份模型、材质细节。具体实现和设备验证边界统一见[结构与性能](../../doc/01-子文档/17-V3交互骨架与内容架构.md#82-结构与性能)。
- 悬停只出现标题、地区、时长、小图与短预览；点击目标后横向进入右侧档案阅读位，原槽位保留空位。
- 详情页的“继续/开始实训”才调用真实开课服务；收回详情不会改变在学状态。教师使用同一界面打开真实学生档案。
- 保留正式Logo；蟳埔首页插图按确认稿重建，其余课程使用现有情境图片。设计图中的方向箭头、阶段编号和“附近暂停”等注解不作为正式控件绘制。

## 2. 实现责任

| 内容 | 唯一入口 |
| --- | --- |
| 三维档案、镜头、材质、投影和鼠标命中 | [renderer.ts](../../apps/web/src/v2/pages/archive-field/renderer.ts) |
| 波浪、邻域暂停、恢复与真实档案映射 | [motion.ts](../../apps/web/src/v2/pages/archive-field/motion.ts) |
| 搜索、筛选、预览、目录及详情状态 | [archive-stage.tsx](../../apps/web/src/v2/pages/archive-stage.tsx) |
| 抽出与归位、可读详情和真正进入动作 | [reader.tsx](../../apps/web/src/v2/pages/archive-field/reader.tsx) |
| 排版、颜色与响应式 | [archive.css](../../apps/web/src/v2/pages/archive.css) |

每个档案簇引用一条真实课程或学生记录；无名薄片提供空间结构，不产生新的课程、学生或成绩。画面、DOM预览和打开动作共用同一个档案ID。渲染循环独立于React状态更新，不逐帧重建页面。

黑色纸板材质由内置Image Gen生成，原图位于正式资产目录 apps/web/public/assets/archive/charcoal-paper.png。它仅作为局部纸板材质，整张概念图没有被当成网页背景。提示词见[材质记录](材质记录.md)。

## 3. 对照检查

| 项目 | 要核对的内容 |
| --- | --- |
| 构图 | 长边方向、密集程度、前后层次与视口填充 |
| 物体 | 薄片厚度、灰色纸边、黄铜封签、哑光纹理和遮挡 |
| 排版 | 品牌、导航、预览标题和详情正文的大小与留白 |
| 状态 | 局部真正停止，远处继续；点击留下空位并进入横向阅读位 |
| 业务 | 看详情没有开课请求；实训按钮、单课二次确认与教师档案可用 |
| 操作 | 键盘、触屏、减少动态、搜索和筛选都可以操作 |
| 稳定性 | 异步挂载取消、返回再进入、资源释放与渲染异常能正确处理 |
