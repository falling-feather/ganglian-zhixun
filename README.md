# 岗链智训

面向职业教育融媒体岗位群的实训 Demo。学生在蟳埔社区、榕江赛事街区和青岚山地景区开展调查、记录、制作与复盘；教师在开课前创作人物和任务，查阅学生作品、逐维评阅并安排后续训练。世界事实与行动由同一权威内核提交。

**当前版本 V3.0.0，主线为 main。** 五门课程，三地区各20个场景与20名主要人物，每课12个调查方向及4种轮换委托。档案首页、渐进地图、人物好友与关系记忆、私人笔记、课前人物节点编辑、作品送审及教师评阅已经接通。单人同时只执行一门课，放弃旧课后换课需要二次确认。

[开发者文档](doc/01-开发者文档.md)说明当前实现，[V3交付手册](doc/01-子文档/19-V3成品交付与验收.md)提供体验步骤和实际验证，[项目规划](doc/02-项目规划.md)保存后续边界。无模型配置时可运行规则演示，作品分数保持待评；教师可直接审读已提交作品逐维评分。真实模型能力以调用回执为准。真人学习时长、教学效果与专业效度尚未验证。

## 直接体验

公开学生导览的实现、功能范围和后端托管准备见[部署说明](deploy/README.md)。公开导览支持场景、人物与资料浏览、私人笔记和作品草稿导出；完整系统的实时 AI、教师评分与云端保存仍需要独立后端，不能把下述本机功能说明理解为公网已全部接通。

Windows 用户在仓库根目录双击：

```text
启动融岗智训.cmd
```

或在 PowerShell 中选择身份并决定是否使用全新数据：

```powershell
.\启动融岗智训.ps1 -Role student -FreshData
.\启动融岗智训.ps1 -Role teacher
.\启动融岗智训.ps1 -Role admin
```

默认地址：

- Web：`http://127.0.0.1:4173`
- API：`http://127.0.0.1:3001`
- 演示数据：`.local/data/`

停止时输入 `stop` 后回车，或按 `Ctrl+C`。开发者也可直接在仓库根目录执行：

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm start
```

## 打开仓库时看到什么

```text
揭榜挂帅/
├── apps/                    # API 与三角色 Web 应用
├── packages/                # 契约、课程、世界、Agent、模型与适配器
├── scripts/                 # 启动、验证、发布和数据安全脚本
├── e2e/                     # 浏览器黄金链
├── artifacts/               # 可复验技术/赛事证据
├── doc/                     # 当前实现、规划、历史与架构文档
├── 演示/                    # 77 页演示手册、48 张真实截图及可复建源文件
├── 资料/                    # 四类决策资料、历史归档和视觉资产
├── .local/                 # 本机依赖、隔离验证及可恢复的旧目录归档
├── .local-secrets/          # 本机密钥原件，Git 忽略
├── 启动融岗智训.cmd
└── package.json
```

程序源码已直接外露在仓库根目录，不再藏在“工作区/原型开发”二级目录。活跃资料只分为赛事要求、浙传专业特色、智能体技术路线和职业教育依据；旧企划、旧调研与对话快照已移入历史归档。完整说明见[资料索引](资料/资料索引.md)。

四套旧演示数据和两套独立前端已退役至本机 `.local/retired-v260/`；正式视觉与来源保留在[视觉基准](资料/91-视觉与演示资产/节点探索视觉基准/README.md)。`.local` 与 `.local-secrets` 继续使用，默认运行数据统一为 `.local/data`，新空白演示放在 `.local/fresh-runs`。[目录处置依据](doc/01-开发者文档.md#19-v26工作区整理)记录检查范围。

## 工程检查

```powershell
corepack pnpm preflight
corepack pnpm check:versions
corepack pnpm check:docs
corepack pnpm check:secrets
corepack pnpm typecheck:packages
corepack pnpm test:packages
corepack pnpm build
corepack pnpm start:smoke
```

`pnpm check` 还包含生产构建和 Playwright 全链，耗时更长。真实模型测试必须使用根目录被忽略的 `.env.local`；不要把密钥写入源码、文档、截图、终端输出或 Git。
