# 岗链智训

面向职业教育融媒体岗位的教学实训智能体平台。学生在仿真岗位现场开展采访、核验与作品交付，教师配置课程并结合过程证据和实际作品复核。

项目源自2026年度中国青年科技创新“揭榜挂帅”擂台赛 XA-202603 榜题，历史名称为“融岗智训”。当前程序基线为 **V3.0.1**，后续维护使用普通提交记录。

## 分支安排

| 分支 | 内容与用途 |
| --- | --- |
| [main](https://github.com/falling-feather/ganglian-zhixun/tree/main) | 完整程序与当前工程文档，作为继续开发、运行和部署的主线 |
| [codex/research-archive](https://github.com/falling-feather/ganglian-zhixun/tree/codex/research-archive) | 前期赛事研究、选题比较、专业依据和技术路线；分支目录仅保留研究资料 |

研究归档按原日期保存，旧方案中的“当前”“待开发”只对应当时阶段。main中的资料01—04保留当前设计采用的依据和运行所需原件。开发、修复和部署分支从main短期建立，合入后清理。

最终比赛提交包由团队另行保存，报名信息、签章原件及其他个人资料不进入公开仓库或夜航研究资料库。

## 程序范围

main包含React师生前端、Fastify服务端及共享包。现有内容覆盖蟳埔、榕江、青岚三地区五门课程；课程、人物与事件包含教学仿真，真实专业原件及使用范围见[资料索引](资料/资料索引.md)。

本地运行从[启动说明](doc/01-开发者文档.md#11-启动和体验当前版本)开始，环境与依赖以仓库配置为准。默认规则模式可运行本地流程；在线模型、语音与OCR需分别配置和验证。

工程测试、真实师生反馈、专业效度和线上运行分别记录，不以历史截图或静态导览代表完整系统验收。学习记录、私有配置、模型缓存和本机生成产物不随Git分发。
