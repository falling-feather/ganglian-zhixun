# 岗链智训 · 作品代码

职业教育融媒体岗位实训 Demo，提交版基于 V3.0.1，封装日期2026-09-14。提供学生端、教师端、课程、后端和运行素材。管理页面与入口已禁用；doc仅保留[开发者文档](doc/01-开发者文档.md)。

## 1. 首次启动

1. 完整解压到可写目录，不要在压缩包内运行。
2. 安装Node.js，推荐24.20.0或更新的24.x；项目使用pnpm 11.9.0。终端须能执行node和corepack；缺少Corepack时执行 `npm install -g corepack`。
3. Windows双击 `启动融岗智训.cmd`。首次安装依赖和构建需要联网，保持终端打开。
4. 打开 **http://127.0.0.1:4173/**，API端口为3001。

Windows、macOS和Linux也可在项目根目录执行：

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm start
```

停止时在终端输入 `stop` 回车，或Ctrl+C，等待正常退出。不要同时启动两套使用同一数据目录的服务。PowerShell入口支持 `./启动融岗智训.ps1 -Role student` 或 `-Role teacher`。

## 2. 演示账号

标识动画后出现黑白档案。点击翻开，右页的账号可一键填入。统一密码 **Demo2026**。

| 入口 | 账号 | 身份 |
| --- | --- | --- |
| 教师 | teacher | 演示教师，管理A/B两班 |
| 学生 | student1 | 学生1，A班 |
| 学生 | student2 | 学生2，A班 |
| 学生 | student3 | 学生3，B班 |

两班各10名测试学生，其他17人只展示未开课名册，不制造成绩。账号与名册启动时自动初始化，不需要作者数据库。三个学生各自保存课程、作品和私人笔记。

## 3. 学生操作

1. 选择课程档案，悬停预览，或“展开课程”从列表选择。
2. 进入后阅读委托，通过地图、出口、人物和资料开展调查，不必先找固定人物。
3. 拖动环视、滚轮缩放；点击人物交流，协商联系、资料范围与引荐。
4. 右下角“采访本”是私人多页笔记，自动保存，教师看不到未交笔记。
5. “工作台”填写成果，先保存再锁定送审。笔记副本与纸质笔记照片自愿附交，也可只交作品。
6. “作品”回看提交与评价。一人同时一门在学课；换课放弃需二次确认，历史与旧作品保留。

五课覆盖社区采访、赛事采编、发布回应、素材版权和暴雨服务报道，位于蟳埔、榕江、青岚三地区。人物、事件与平台数字属于教学仿真，公开专业资料另有来源。

## 4. 教师操作

1. 登录teacher，通过下拉选择A/B班；“展开档案”可直接从名单选学生。
2. 查看当前课程、历史作品和有效评价；未形成记录时保持未开始／待评。
3. “课程导演”新增人物，配置岗位、性格、知识、场景、立绘与关系。默认精简模式，专业模式支持节点拖动、连线和属性编辑。
4. 保存后发布，只影响之后新开课程；在学课保持原发布版本。未发布编辑在当前浏览器暂存。
5. “教学资料”导入资料并查看处理状态；从学生档案进入评阅，以真实交付作品为依据。

## 5. 模型与可选扩展

本次定向提交包已在服务端 `.env.local` 预置获授权的DeepSeek密钥，默认使用deepseek-flash，启动后无需再填写密钥。若以后更换模型账号，可修改以下字段并重启：

```ini
MODEL_PROVIDER=deepseek
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_API_KEY=
SHOWCASE_DETERMINISTIC_STRUCTURED=0
```

确认账号支持图片后才设置 `DEEPSEEK_VISION_MODEL=deepseek-flash`。本包按授权包含有效模型密钥，仅供本次定向提交和演示，不要公开托管这个含密钥包。讯飞扩展需单独配置，mock不代表在线服务。

PDF识别、语音和本地语义检索需Python3.11、ffmpeg及相应模型。Windows可在PowerShell7运行：

```powershell
./scripts/setup-ai025-runtime.ps1
./scripts/setup-be007-runtime.ps1
```

首次下载可能较大。服务启动后另开终端执行 `corepack pnpm content:prepare`，导入包内四类公开PDF并建立五课索引，回执位于 `.local/content-preparation/receipt.json`。未安装的扩展不视为已可用。

## 6. 保存和故障处理

- 数据保存在 `.local/data/`，重启复用；本包不含作者学习历史和私人笔记。
- 新演示用 `corepack pnpm start:fresh`，创建新目录，不删旧数据。
- 端口被占用时先正常关闭旧程序；服务重启或登录过期后回首页登录。
- 数据目录占用时先确认旧服务停止，不要直接删锁或学习数据，恢复工具见开发者文档。
- 新人物要在新开课程中查看；旧场冻结是正常行为。
- `/admin/...` 显示管理页面已禁用，不建立管理员身份。公开演示凭据及内部工程API不是生产身份平台。

## 7. 包体

apps为前后端与素材；packages为契约、课程、模型、世界和数据内核；scripts为必要工具；artifacts为固定运行数据；资料含四类公开PDF。doc只有01号文档。

文件清单记录路径、大小和SHA-256，压缩包另附校验值。管理页面模块、其他doc、设计稿、测试产物、Git历史、node_modules、dist、模型权重和本机运行库不打包；唯独服务端.env.local按本次授权包含模型密钥；首次运行会生成依赖和构建产物。

本轮执行生产构建与封包完整性处理，未重跑全量测试，也未验证新机首次安装、真人教学效果或学校并发。当前交付用于评委运行Demo。
